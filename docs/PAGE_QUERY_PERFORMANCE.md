# 普通页面查询延迟：Mac 本机 HTTP 基准

## 目标与测量边界

PRD §2.3 要求“普通查询在推荐环境中不超过 2 秒”。此处把普通页面对应的读取定义为前端入口 HTML，以及只读账号可访问的总览、数据集、因子、任务、报告列表。工具 [`../tools/benchmark_page_queries.py`](../tools/benchmark_page_queries.py) 从宿主机经 `127.0.0.1` 请求现有 OrbStack Compose 栈，计时包含 HTTP 响应读取和 JSON 解码；登录仅获取 Token，不计时。业务测量请求全为 GET，不导入数据、不提交任务、不生成报告。

每个入口先读取一次，再连续读取 5 次；记录首次、重复中位数和全部 6 次最大值。**“首次”不代表服务冷启动**：测量时 API/Web 已运行，数据库和操作系统缓存可能是热的。任何一次超过 2 秒，工具退出码为 1。工具只接受本机 loopback 地址，避免把演示密码或 Token 送到外部主机；输出不含密码或 Token。

## 2026-10-14 实测

环境：macOS 14.6.1 arm64，Python 3.13.3，Mac OrbStack 的 `fbl` 五服务；只读账号。时间为 2026-10-14 17:27:44（北京时间）。目录规模：2 个数据版本、6 个内置因子、26 个任务、26 份报告。单位为毫秒，四舍五入到 0.1 毫秒。

| 入口 | 首次读取 | 重复中位数 | 6 次最大值 | 条目数 |
| --- | ---: | ---: | ---: | ---: |
| Web 入口 HTML | 2.0 | 1.1 | 2.0 | — |
| 项目总览 API | 51.1 | 52.7 | 72.8 | — |
| 数据集列表 | 4.1 | 2.5 | 4.1 | 2 |
| 因子列表 | 1.9 | 2.0 | 2.7 | 6 |
| 任务列表 | 67.9 | 64.0 | 86.4 | 26 |
| 报告列表 | 23.8 | 22.6 | 42.6 | 26 |

本次六个入口的全部请求均低于 2 秒。可复测：先在环境中设置 `FACTORLAB_DEMO_VIEWER_PASSWORD`，启动同一 Compose 栈，再运行：

```bash
python tools/benchmark_page_queries.py
```

默认对每个入口测量首次 + 5 次重复；可用 `--samples`（至少 3）和 `--limit-seconds` 调整。标准输出为 JSON，适合保留为私有验收证据。不要把密码放在命令行参数、截图或报告中。

## 2026-10-14 浏览器抽样

使用 Playwright CLI 的 HeadlessChrome 155、1280×720 视口，在同一 Mac/OrbStack 栈以只读用户登录 `http://localhost:5173/`。三次已登录刷新均显示完整总览卡片（2 个数据版本、6 个因子、26 个任务与 26 份报告）；浏览器 Navigation Timing 的导航持续时间分别为 77.8、19.8、17.4 ms，First Contentful Paint 分别为 88、36、44 ms。这两个浏览器指标**不是**“全部 API 数据到齐”或“页面可交互”的时间。

在已登录页面分别点击导航一次，从点击事件到目标标题及预期列表／预览元素出现后再经过两帧绘制的耗时为：数据集 29.5 ms、因子库 31.5 ms、任务中心 150.7 ms、报告中心 100.9 ms、返回项目总览 31.7 ms。任务与报告页均有 26 项；报告页等待预览 iframe 元素出现，但未计量 iframe 内全部内容绘制。**每个切页只有一次样本**，且页面可能使用已加载缓存，因此仅作浏览器功能与体验抽样，不能推断总体百分位数或冷启动性能。

最初从 `http://127.0.0.1:5173/` 登录被旧默认 CORS 配置阻拦，改用文档指定的 `localhost` 后正常。随后 API 默认允许两个本机前端来源，并为 Web 增加 SVG favicon；只重建现有栈的 API/Web 后，在全新浏览器会话从 `127.0.0.1:5173` 成功登录，只读总览正确显示，控制台无错误，`/favicon.svg` 为 HTTP 200。相关浏览器快照与控制台记录保存在 Git 忽略的 `output/playwright/fbl-page-qa-20261014/`，可能含演示账号输入内容，不应公开分发。

## 不等同于完整页面性能验收

浏览器抽样补充了已登录刷新的 FCP 和五次切页观察，但仍未测真正冷启动、完整 JavaScript/图表加载时点、交互响应分布、历史包预览的整包哈希校验、报告下载、并发负载或 Windows。样本规模也仅为当前演示栈，不代表更大任务库。故 PRD 的“页面性能”仍只能标记为**部分验证：Mac 本地 HTTP 基准和浏览器抽样通过**，不能写成完整跨环境达标。D 负责在正式彩排中记录实际页面体验；A 在最终推荐环境重复测量。
