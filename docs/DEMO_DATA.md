# 离线演示数据说明

## 定位

`data/sample/daily_prices.csv` 是随仓库发布的合成行情快照，用于离线演示、自动化测试和课程验收。它不来自交易所或数据供应商，不代表真实证券，也不能支持任何投资结论。

当前目录版本为 `demo_daily` 0.2.0：

- 20 只虚拟股票：`DEMO01`—`DEMO20`；
- 2025-01-02 至 2025-06-18，共 120 个周一至周五日期；
- 2,400 行、12 个字段；
- 覆盖价格、成交、复权、换手率、总市值和市盈率；
- 可直接执行六个内置因子及等权多因子组合。

日期仅排除了周末，没有复刻中国法定节假日。价格和基本面字段由确定性数学公式构造，刻意保留横截面与时间序列差异，以便界面和报告能展示非空结果。

## 复现与验收

在项目根目录运行：

```bash
python tools/generate_demo_dataset.py --check
python tools/benchmark_demo_research.py
```

第一条命令校验已提交 CSV 与生成器输出完全一致；第二条命令依次完成六个因子的计算和检验。课程演示基线要求六因子总耗时不超过 10 秒。该阈值是防止明显性能回退的工程门槛，不是生产性能承诺。

PRD 的 300 只股票、三年日频、单因子 60 秒目标由独立的 [`PERFORMANCE_ACCEPTANCE.md`](PERFORMANCE_ACCEPTANCE.md) 与 `tools/benchmark_prd_scale.py` 检查，不能用上述小样本基线代替。

如需调整数据公式，应同步更新生成器、快照、数据目录版本、本说明和相关测试，不能直接手改 CSV。
