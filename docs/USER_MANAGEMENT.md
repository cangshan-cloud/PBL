# 用户管理说明

## 1. 账号生命周期

课程版不开放自行注册。管理员在“用户管理”页面创建账号并设置初始角色和密码，随后可以修改显示名称、角色以及启用状态。用户名创建后保持不变，用于登录和审计识别。

停用账号后：

- 新登录立即被拒绝；
- 已经签发的 JWT 在下一次接口请求时也会被拒绝；
- 历史实验、任务、报告和日志不会删除；
- 管理员重新启用后，该用户可以再次登录。

## 2. 管理保护规则

- 只有管理员可以查看用户列表、创建账号和修改账号。
- 管理员不能停用自己的账号。
- 管理员不能把自己的角色降为研究员或只读用户。
- 系统必须始终保留至少一个启用状态的管理员。
- 停用用户不会级联删除其研究记录。

角色修改实时生效。后端每次请求都会从数据库读取当前用户和角色，不直接信任 JWT 中签发时的旧角色。

## 3. 当前边界

- 密码至少 10 位，使用随机盐 PBKDF2-SHA256 保存。
- 暂不提供用户自行改密、忘记密码、邮件验证和单点登录。
- 课程部署首次初始化前，应通过环境变量修改三个预置账号密码。
- 目前不删除账号；停用是保留历史归属的安全替代方案。

## 4. 接口

- `GET /api/v1/users`：管理员获取用户列表。
- `POST /api/v1/users`：管理员创建账号。
- `PATCH /api/v1/users/{user_id}`：修改 `display_name`、`role` 或 `is_active`。
