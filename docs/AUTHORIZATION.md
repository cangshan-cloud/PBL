# 登录与权限说明

## 1. 角色权限矩阵

| 功能 | 管理员 `admin` | 研究员 `researcher` | 只读用户 `viewer` |
| --- | --- | --- | --- |
| 查看数据版本与因子 | 是 | 是 | 是 |
| 导入、发布数据版本 | 是 | 否 | 否 |
| 创建研究任务 | 是 | 是 | 否 |
| 查看任务与报告 | 全部 | 仅本人创建 | 全部 |
| 创建、查看、启停用户 | 是 | 否 | 否 |

权限由后端接口强制校验；前端隐藏按钮只是交互辅助，不能替代后端鉴权。

## 2. 开发环境预置账号

首次启动时系统自动创建三个演示账号：

| 用户名 | 默认密码 | 角色 |
| --- | --- | --- |
| `admin` | `admin12345` | 管理员 |
| `researcher` | `research12345` | 研究员 |
| `viewer` | `viewer12345` | 只读用户 |

这些密码仅用于本地课程演示。共享部署前必须在 `.env` 中修改三个
`BOOTSTRAP_*_PASSWORD` 变量，并将 `JWT_SECRET` 设置为足够长的随机值。已经创建的账号不会因修改环境变量而自动改密；课程版暂未提供改密接口，应在首次初始化数据库前完成配置。

## 3. 鉴权机制

- 登录成功后签发有时效的 JWT Bearer Token，默认有效期为 120 分钟。
- 密码使用带随机盐的 PBKDF2-SHA256 摘要保存，不存储明文。
- 前端把 Token 保存在浏览器本地存储中，重新打开页面时调用 `/auth/me` 校验会话。
- Token 过期或无效时返回 HTTP 401；角色权限不足返回 HTTP 403。
- 停用状态和当前角色在每次请求时从数据库校验，因此旧 Token 不会保留已撤销权限。
- 首期为少量研究人员私有部署，不实现注册、找回密码、刷新令牌和第三方单点登录。

完整账号生命周期和管理员保护规则见 [USER_MANAGEMENT.md](USER_MANAGEMENT.md)。

## 4. 验证命令

在项目根目录运行：

```bash
cd backend
../.venv/bin/python scripts/verify_permissions.py
```

该脚本使用临时 SQLite 数据库，不会改动开发数据；它会验证未登录拦截、管理员用户管理、只读用户禁止创建任务，以及不同研究员之间的任务和报告隔离。
