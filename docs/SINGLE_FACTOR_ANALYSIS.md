# 单因子检验口径

## 1. 时间对齐

交易日 `t` 收盘后形成因子值，使用下一**市场交易日**的收盘到收盘收益作为前向收益。普通 CSV 平台任务从**整份已发布数据集**的日期并集推断市场日历，之后才按证券列表筛选研究对象；未选证券仍可提供日历日。某证券若缺少紧邻下一市场日的记录，不把其更晚的下一条记录当作 `t+1`，该信号不进入有标签检验。滚动因子的回看窗口也须覆盖连续市场日，不将缺行前后的观测压缩成完整窗口。直接调用底层因子函数且不传日历时，仅从传入行推断日期。系统不会用 `t+1` 的数据计算 `t` 日因子。财务因子接入真实数据时还必须按公告日期生效。

用户可以指定证券列表与因子日期范围；系统会保留起始日前的回看历史。详细规则见 [SAMPLE_SELECTION.md](SAMPLE_SELECTION.md)。

进入检验前，每个“证券 × 交易日”只能有一条观测，因子值与前向收益必须是有限数；不满足时任务报错，不生成指标或报告。正式 CSV 导入也独立检查重复证券日期。

## 2. 截面预处理

预处理在每个交易日的股票截面内独立完成，默认顺序如下：

1. MAD 去极值：以截面中位数为中心，将数值限制在 `中位数 ± 3 × 1.4826 × MAD`。
2. Z-score 标准化：减去截面均值后除以总体标准差。

两个步骤均可在研究工作台关闭。若截面 MAD 或标准差为零，系统保留原值，避免除零。预处理参数随实验保存，能够从任务详情复现。

计算时先按当日因子值最大绝对值缩放，再执行同一 MAD 与 Z-score 规则，避免极大但有限的截面值在均值、离差或平方和阶段溢出。未启用预处理、或实际未发生去极值且无法标准化时，保留原始因子值，不做不必要的浮点往返。`mad_scale` 必须是有限正数。

## 3. 指标定义

| 指标 | 当前口径 |
| --- | --- |
| 覆盖量 | 进入检验的“证券 × 交易日”观测数 |
| 逐日样本诊断 | 新 Run 的 `daily_coverage` 包含所选市场日历中**每一天**，即使当天没有任何有效观测。普通 CSV 的候选数是所选证券当日存在的原始记录数；历史包的候选数是当日历史成员数。有效数是已形成有限因子与下一日收益的观测数；回看预热与末尾无次日标签也可能形成差额，不能仅凭差额归因于停牌、窗口、缺行或财务披露；历史包准确原因仍见独立审计。候选为零时覆盖率为 `null` 而非零；无观测日的 IC／分组状态为 `no_observation`，不进入原有分组跳过计数 |
| IC | 每日截面因子值与下一日收益的 Pearson 相关系数 |
| Rank IC | 每日因子排名与下一日收益排名的 Pearson 相关，即 Spearman 相关 |
| IC 均值 | 所有有效日 IC 的算术平均 |
| IC 标准差 | 有效日 IC 的总体标准差 |
| ICIR | IC 均值除以 IC 总体标准差，当前不年化 |
| IC 为正比例 | IC 大于零的有效交易日占比 |
| IC 分布 | 将有效日 IC 按 `[-1, 1]` 固定为 10 个宽度 0.2 的区间；左闭右开，最后一区间包含 1；空值不计入 |
| 分组收益 | 每日按因子从低到高等数量分组；部分因子同值时按证券代码升序固定次序，避免导入行顺序改变分组。若某日全截面因子同值，则该日没有可排序信号，保留 IC 空值但不计算分组及多空收益，并在结果中计入 `group_skipped_constant_factor_days`。组内下一日收益等权平均；展示的 `mean_return` 是有该组成员的交易日收益的算术平均，每个有效交易日权重相同，不把所有证券日收益混合加权 |
| 每日分组最低样本数 | 某日有效证券数少于目标分组数时，该日不可能形成完整分组，保留可计算的 IC，但跳过分组及多空收益，计入 `group_skipped_insufficient_sample_days`；总体所选证券数达到分组数不代表每日都满足 |
| 分组净值 | 各组日收益按 `净值 × (1 + 日收益)` 连乘，初值为 1 |
| 多空收益 | 最高因子组收益减最低因子组收益 |
| 多空净值 | 多空日收益连乘得到的净值，未使用现金或保证金模型 |
| 头部组换手率 | 相邻截面最高组等权目标权重变化的绝对值之和除以 2，再对后续有效截面取均值；组内数量变化时不等同于简单成员交集比率 |

## 4. 当前假设与限制

- 分组收益和多空收益未扣除佣金、印花税、冲击成本及滑点。
- 尚未模拟停牌、涨跌停、成交量约束和实际撮合。
- 普通 CSV 的市场日历由整份数据集的证券日期并集推断，并非独立交易所日历；若数据集内所有证券同日缺行，仍无法识别该日是否为市场交易日。真实历史包使用独立封存日历与交易状态，口径更严格。
- 尚未实现行业中性化、市值中性化及多因子相关性矩阵。
- 仓库样例数据是人工构造数据，只用于证明软件流程，不能形成投资结论。
- 指标适合课程版因子初筛，不等同于可直接实盘的策略回测。
- 旧任务结果保持其创建时的代码版本和指标数值；此次分组均值口径修正仅作用于新运行任务。比较旧新报告前，应核对代码指纹与每日样本数。
- 旧任务中可能存在“下一条证券记录跨越多个市场日”的收益标签；本次缺行处理只作用于新任务，比较旧新报告需同时核对样本缺行情况。
- 全截面因子同值日跳过分组，仅作用于新任务；组净值和多空序列只包含可分组日期，不补零、不虚构持仓期间收益。成本与换手仍按相邻可分组截面近似比较，不构成完整可交易回测。
- 每日样本不足的分组跳过也仅作用于新任务；覆盖量仍是全部进入检验的证券日观测数，不应误读为分组实际样本量。
- Pearson 计算会先按每侧最大绝对值缩放，再中心化计算，避免极大但有限的输入在平方和中溢出；这不保证极端收益下的净值连乘或预处理也不会溢出。
- 新任务在结构化结果落库前检查所有浮点指标；若极端输入使分组收益、净值或 ICIR 等派生结果变成 NaN/无穷大，则明确报错，不生成看似成功但不可序列化的研究结果。

## 5. 结果输出

结构化结果随 Run 保存，包括 IC 序列与分布、分组平均收益、分组净值序列、多空收益与净值序列、换手率和预处理参数。前端展示摘要指标、IC 分布、各组净值和多空净值曲线；独立 HTML 报告内嵌 IC／Rank IC、各组净值、毛／成本后多空净值 SVG 曲线及 IC 分布。各组净值图直接读取本次 Run 保存的 `group_nav`，不以平均收益重新推算。IC 空值以曲线断点表示，不替换为零。

隔离 HTTP 回归另覆盖稀疏样本闭环：同一 CSV 同时触发全同值日、每日有效证券数不足及正常可分组日，核对任务结果、复现包、动态结论和 HTML 报告；日期范围内完全没有可分组日时，多空收益为空、报告显示“暂无有效时间序列”，不会补画零收益净值。
工作台与 HTML 报告的分组区域在无可计算结果时显示明确的空态，结论草稿也不把缺失多空收益描述成实际表现；这些提示不影响 IC 的独立统计。
