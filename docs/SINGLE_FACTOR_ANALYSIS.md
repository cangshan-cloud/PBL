# 单因子检验口径

## 1. 时间对齐

交易日 `t` 收盘后形成因子值，使用下一**市场交易日**的收盘到收盘收益作为前向收益。普通 CSV 平台任务从**整份已发布数据集**的日期并集推断市场日历，之后才按证券列表筛选研究对象；未选证券仍可提供日历日。某证券若缺少紧邻下一市场日的记录，不把其更晚的下一条记录当作 `t+1`，该信号不进入有标签检验。滚动因子的回看窗口也须覆盖连续市场日，不将缺行前后的观测压缩成完整窗口。直接调用底层因子函数且不传日历时，仅从传入行推断日期。系统不会用 `t+1` 的数据计算 `t` 日因子。财务因子接入真实数据时还必须按公告日期生效。

用户可以指定证券列表与因子日期范围；系统会保留起始日前的回看历史。详细规则见 [SAMPLE_SELECTION.md](SAMPLE_SELECTION.md)。

进入检验前，每个“证券 × 交易日”只能有一条观测，因子值与前向收益必须是有限数；不满足时任务报错，不生成指标或报告。正式 CSV 导入也独立检查重复证券日期。

## 2. 截面预处理

预处理在每个交易日的股票截面内独立完成，默认顺序如下：

1. MAD 去极值：以截面中位数为中心，将数值限制在 `中位数 ± 3 × 1.4826 × MAD`。
2. Z-score 标准化：减去截面均值后除以总体标准差。

两个步骤均可在研究工作台关闭。若截面 MAD 或标准差为零，系统保留原值，避免除零。预处理参数随实验保存，能够从任务详情复现。

计算时先按当日因子值最大绝对值缩放，再执行同一 MAD 与 Z-score 规则，避免极大但有限的截面值在均值、离差或平方和阶段溢出。未启用预处理、或实际未发生去极值且无法标准化时，保留原始因子值，不做不必要的浮点往返。`mad_scale` 必须是有限正数。

## 3. 指标定义

| 指标 | 当前口径 |
| --- | --- |
| 覆盖量 | 进入检验的“证券 × 交易日”观测数 |
| 逐日样本诊断 | 新 Run 的 `daily_coverage` 包含所选市场日历中**每一天**，即使当天没有任何有效观测。普通 CSV 的候选数是所选证券当日存在的原始记录数；历史包的候选数是当日历史成员数。有效数是已形成有限因子与下一日收益的观测数；回看预热与末尾无次日标签也可能形成差额，不能仅凭差额归因于停牌、窗口、缺行或财务披露；历史包准确原因仍见独立审计。候选为零时覆盖率为 `null` 而非零；无观测日的 IC／分组状态为 `no_observation`，不进入原有分组跳过计数 |
| IC | 每日截面因子值与下一日收益的 Pearson 相关系数 |
| Rank IC | 每日因子排名与下一日收益排名的 Pearson 相关，即 Spearman 相关 |
| IC 均值 | 所有有效日 IC 的算术平均 |
| IC 标准差 | 有效日 IC 的总体标准差 |
| ICIR | IC 均值除以 IC 总体标准差，当前不年化 |
| IC 为正比例 | IC 大于零的有效交易日占比 |
| IC 分布 | 将有效日 IC 按 `[-1, 1]` 固定为 10 个宽度 0.2 的区间；左闭右开，最后一区间包含 1；空值不计入 |
| 分组收益 | 每日按因子从低到高等数量分组；部分因子同值时按证券代码升序固定次序，避免导入行顺序改变分组。若某日全截面因子同值，则该日没有可排序信号，保留 IC 空值但不计算分组及多空收益，并在结果中计入 `group_skipped_constant_factor_days`。组内下一日收益等权平均；展示的 `mean_return` 是有该组成员的交易日收益的算术平均，每个有效交易日权重相同，不把所有证券日收益混合加权 |
| 每日分组最低样本数 | 某日有效证券数少于目标分组数时，该日不可能形成完整分组，保留可计算的 IC，但跳过分组及多空收益，计入 `group_skipped_insufficient_sample_days`；总体所选证券数达到分组数不代表每日都满足 |
| 分组净值 | 各组日收益按 `净值 × (1 + 日收益)` 连乘，初值为 1 |
| 多空收益 | 最高因子组收益减最低因子组收益 |
| 多空净值 | 多空日收益连乘得到的净值，未使用现金或保证金模型 |
| 头部组换手率 | 相邻截面最高组等权目标权重变化的绝对值之和除以 2，再对后续有效截面取均值；组内数量变化时不等同于简单成员交集比率 |

研究工作台的逐日样本诊断表每页显示 20 日。可选“只看待核对日”：筛出未形成观测数大于零，或 IC／分组状态并非 `valid` 的日期，保留原日期顺序并从第一页重新分页。它只是排查入口，不自动判定停牌、缺行或数据错误；回看预热及末尾无次日标签也可能入选。页码和筛选仅影响前端可见行；“下载全量诊断 CSV”不受筛选影响，按原顺序输出 Run ID、日期、候选数、有效数、原始覆盖率、未形成观测数和 IC／分组状态码，空值留空。它是浏览器从已取回任务结果生成的诊断副本，不等于经过独立签名的归档或可成交回测；历史模式原有逐日审计 CSV 仍是另一份含因子级审计的服务端出口。全部 `daily_coverage` 仍保存在任务结果。见 [历史页面实点](HISTORICAL_BROWSER_PAGE_QA_2026-10-25.md)及[筛选复点](HISTORICAL_COVERAGE_FILTER_QA_2026-10-25.md)。

任务中心选中已有成功任务时，也展示同一逐日诊断组件及全量 CSV 按钮；按 Run ID 重置筛选与页码，不会把上一任务的视图状态带入下一任务。它读取该任务保存的结果，不重新计算因子或创建新研究任务。见[既有任务复点](HISTORICAL_TASK_COVERAGE_QA_2026-10-25.md)。

逐日诊断 CSV 可与同 Run 复现 JSON 用[离线工具](SERIES_EXPORT_VERIFICATION.md)逐行核对，包括日期、候选/有效/排除数、原始覆盖率及状态码；页面筛选不影响全量下载。旧 Run 留存文件的只读核对为 242 行，见 [CHG-20261027-007](changes/2026-10-27-007-daily-coverage-offline-verification.md)。该核对只能证明两个同源副本一致，不独立证明缺失原因或行情真实性。

任务详情还可按需展开该 Run 已保存的每日 IC、多空毛／成本后净值及各组毛净值曲线；切换任务后面板自动收起，图表的完整 Run 身份随当前选中任务改变。下载按钮保持在面板上方，曲线和 CSV 都读取同一结果对象，不因回看创建新计算。见[隔离页面复点](TASK_SERIES_CHART_BROWSER_QA_2026-10-26.md)。

逐日曲线横轴标出已知日期的起止范围，日期等距排列，**不是自然日间隔**。网页 IC、多空与各组净值图以及新生成的 HTML 报告曲线，现均使用各自保存序列日期与可用 `daily_coverage` 日期的并集；即使所有曲线在某个已知样本日均无值，也在该日断线，不跨过去连线。IC 原有空值仍断线。旧结果若无逐日诊断，只按保存序列日期处理；若序列和诊断共同缺某市场日，图表仍无法凭空恢复该日，完整市场日历及原因须另查数据包/逐日诊断。见[原日期轴验收](CHART_DATE_ALIGNMENT_QA_2026-10-26.md)及 [CHG-20261026-017](changes/2026-10-26-017-chart-known-date-axis.md)。

网页曲线若在两个有效点之间存在“所有显示线都无可绘制值”的已知日期，会出现可展开提示并列出这些日期，便于发现长序列上不显眼的断点。起止边缘没有有效点的日期不计入这一提示；某条线缺值但其他线有值时也不计入。该提示只说明当前图的绘制状态，不推断缺值原因或未记录的市场日，不改变原始序列、CSV 或收益指标。见 [CHG-20261026-019](changes/2026-10-26-019-chart-gap-disclosure.md)。

研究工作台及任务回看的每日相关性图同时绘制 IC 与 Rank IC：两条线共用已知日期轴和零基线，但各自按保存值独立断线，图例显示各自最后一个可绘制值，纵轴范围包含两者。有效截面数及不可绘制数也分别列出；内部全线空缺提示仅在两条线均无值时出现。Rank IC 仅增加网页可视核对，不改变因子计算、报告归档、IC 分布（仍只统计 IC）或逐日 CSV 原值。见 [CHG-20261027-003](changes/2026-10-27-003-rank-ic-web-chart.md)。

图下“核对日期”默认选择当前 Run 最后一个已知日期，可逐日切换或下拉定位；两项读数直接显示保存结果的序列化数值，不套用图例的四位小数。诊断独有日期两项显示“—”并声明没有保存的相关性记录；有原记录但空值也不补零。切换 Run 会重置选中日期。该区域仅方便人工核图，完整序列仍应使用带 Run ID 的每日 CSV/复现包核对；日期列表不是独立交易日历。见[隔离浏览器验收](IC_DATE_INSPECTOR_QA_2026-10-27.md)及 [CHG-20261027-004](changes/2026-10-27-004-ic-date-inspector.md)。

网页多空和各组净值图现也有独立“核对日期”：分别显示该日保存的毛／成本后净值及各组净值，未保存的组别显示“—”；只有逐日诊断日期而无净值记录时明确提示，不沿用前值。三图选日互不联动，换 Run 重置到新 Run 的末日。该读数不改变图例末值、CSV、复现包或报告指标，不额外推断交易日和可成交收益。见[隔离浏览器验收](NAV_DATE_INSPECTOR_QA_2026-10-27.md)及 [CHG-20261027-005](changes/2026-10-27-005-nav-date-inspector.md)。

若当前 Run 带已保存的时间切分结果，网页 IC 图另列研究期、隔离信号日与验证期日期，并在选中日期下标注所属范围。全区间原曲线可能包含隔离日的点，而该日不参与任一分段摘要；“研究期/验证期范围”仅是日期分类，不保证该日 IC 可计算。无切分结果的 Run 不显示阶段提示。见[构造 UI 验收](IC_SPLIT_DATE_CONTEXT_QA_2026-10-27.md)及 [CHG-20261027-006](changes/2026-10-27-006-ic-split-date-context.md)。

新生成的 HTML 报告三类曲线也按同一“内部全线空缺”规则显示可展开日期提示；旧报告归档不回写。网页正向提示已用浏览器会话内构造响应验收，非真实交易日证据；报告提示的后续浏览器实点见下段。见[网页浏览器验收](CHART_GAP_BROWSER_QA_2026-10-26.md)及 [CHG-20261026-020](changes/2026-10-26-020-report-chart-gap-disclosure.md)。

报告断点提示已在合成 HTML 浏览器中实点；390px 窄屏下，报告图保持最低可读宽度并可在图内横向滚动，长复现版本号在单列卡片中折行，整页不被撑宽。打印时图宽恢复自适应。合成日期不是真实市场证据，新版本不回写旧归档。见[窄屏验收](REPORT_GAP_MOBILE_QA_2026-10-27.md)及 [CHG-20261027-001](changes/2026-10-27-001-report-mobile-chart-layout.md)。

默认打印版不展开宽幅逐日核对表，而会注明该表的已知日期数及明细未包含，并指向同 Run HTML、逐日 CSV 与复现包；网页版仍可展开查看。这样避免数百日表格使课程报告页数失控，同时不把仅有表格标题的 PDF 误认为含完整明细。合成样例六页 PDF 已逐页检查，真实任务打印版仍待实测。见[打印验收](REPORT_PRINT_QA_2026-10-27.md)及 [CHG-20261027-002](changes/2026-10-27-002-report-print-detail-disclosure.md)。

新生成的 HTML 报告的各组净值图按各组保存日期与逐日诊断日期的并集对齐，在已知缺日时断线；报告三张曲线均注明已知结果/诊断日等距、不代表自然日间隔。既有报告归档不回写，仍以其生成时版本为准。

新报告在曲线后提供默认折叠的“逐日序列核对表”：按 IC、Rank IC、多空毛／成本后净值和各组净值的保存日期，以及可用 `daily_coverage` 诊断日期的并集展示。已知样本日即使所有曲线无点也保留一行；缺值显示“—”，不补零、不沿用前值。有逐日诊断时表末列展示 IC／分组状态，状态只说明计算情况，不自动解释缺失的具体原因。表内四位小数仅供人工核对图像与日期；完整精度仍以同 Run 结构化结果及逐日 CSV 为准。窄屏可横向滚动；既无曲线点也无逐日诊断日期时不生成空表。旧结果缺 `daily_coverage` 时只按保存序列日期展示；既有归档不追加该表。见[合成报告浏览器验收](REPORT_DAILY_SERIES_TABLE_QA_2026-10-26.md)及 [CHG-20261026-016](changes/2026-10-26-016-report-known-date-coverage.md)。

合成 CSV 的隔离 API 闭环还逐行比较该表与同 Run 复现结果，并核对预览、归档及交付副本；这验证软件交付链路，不构成真实数据或容器运行验收。见 [CHG-20261026-015](changes/2026-10-26-015-report-table-api-binding.md)。

## 4. 当前假设与限制

- 分组收益和多空收益未扣除佣金、印花税、冲击成本及滑点。
- 尚未模拟停牌、涨跌停、成交量约束和实际撮合。
- 普通 CSV 的市场日历由整份数据集的证券日期并集推断，并非独立交易所日历；若数据集内所有证券同日缺行，仍无法识别该日是否为市场交易日。真实历史包使用独立封存日历与交易状态，口径更严格。
- 尚未实现行业中性化、市值中性化及多因子相关性矩阵。
- 仓库样例数据是人工构造数据，只用于证明软件流程，不能形成投资结论。
- 指标适合课程版因子初筛，不等同于可直接实盘的策略回测。
- 旧任务结果保持其创建时的代码版本和指标数值；此次分组均值口径修正仅作用于新运行任务。比较旧新报告前，应核对代码指纹与每日样本数。
- 旧任务中可能存在“下一条证券记录跨越多个市场日”的收益标签；本次缺行处理只作用于新任务，比较旧新报告需同时核对样本缺行情况。
- 全截面因子同值日跳过分组，仅作用于新任务；组净值和多空序列只包含可分组日期，不补零、不虚构持仓期间收益。成本与换手仍按相邻可分组截面近似比较，不构成完整可交易回测。
- 每日样本不足的分组跳过也仅作用于新任务；覆盖量仍是全部进入检验的证券日观测数，不应误读为分组实际样本量。
- Pearson 计算会先按每侧最大绝对值缩放，再中心化计算，避免极大但有限的输入在平方和中溢出；这不保证极端收益下的净值连乘或预处理也不会溢出。
- 新任务在结构化结果落库前检查所有浮点指标；若极端输入使分组收益、净值或 ICIR 等派生结果变成 NaN/无穷大，则明确报错，不生成看似成功但不可序列化的研究结果。

## 5. 结果输出

结构化结果随 Run 保存，包括 IC 序列与分布、分组平均收益、分组净值序列、多空收益与净值序列、换手率和预处理参数。前端展示摘要指标、IC 分布、各组净值和多空净值曲线；独立 HTML 报告内嵌 IC／Rank IC、各组净值、毛／成本后多空净值 SVG 曲线及 IC 分布。各组净值图直接读取本次 Run 保存的 `group_nav`，不以平均收益重新推算。IC 空值以曲线断点表示，不替换为零。

研究工作台和旧任务详情可下载已保存的多空逐日 CSV。每行对应一个有效分组日，包含完整 Run ID、日期、毛日收益与毛净值、双边目标权重换手、成本、成本后日收益与净值，以及单边成本参数（bps）；收益、换手和成本均为比例值，不是百分数。成本按双边换手 × 单边 bps ÷ 10,000 计算，成本后日收益为毛日收益减成本；净值从 1 开始连乘。无有效分组日只导出表头，不补零。文件仅搬运该 Run 的既有研究结果，不补充现金、融资融券、滑点、容量或真实撮合模型，不能视为可成交收益证明。

各组净值也可下载 `run_id,group,date,nav` 长表：按已保存 `group_nav` 中的组别和各组日期顺序展开，每个值是组内等权日收益从 1 连乘的**毛净值**，不扣成本；没有有效分组日时仅输出表头。导出不跨缺失日期补点，也不从期末平均收益倒推逐日曲线。IC、多空和各组净值三种 CSV 可分别用[离线核对工具](SERIES_EXPORT_VERIFICATION.md)与同 Run 复现 JSON 逐行比对。

隔离 HTTP 回归另覆盖稀疏样本闭环：同一 CSV 同时触发全同值日、每日有效证券数不足及正常可分组日，核对任务结果、复现包、动态结论和 HTML 报告；日期范围内完全没有可分组日时，多空收益为空、报告显示“暂无有效时间序列”，不会补画零收益净值。
工作台与 HTML 报告的分组区域在无可计算结果时显示明确的空态，结论草稿也不把缺失多空收益描述成实际表现；这些提示不影响 IC 的独立统计。
