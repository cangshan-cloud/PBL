# 单因子检验口径

## 1. 时间对齐

交易日 `t` 收盘后形成因子值，使用 `t+1` 的收盘到收盘收益作为前向收益。系统不会用 `t+1` 的数据计算 `t` 日因子。财务因子接入真实数据时还必须按公告日期生效。

用户可以指定证券列表与因子日期范围；系统会保留起始日前的回看历史。详细规则见 [SAMPLE_SELECTION.md](SAMPLE_SELECTION.md)。

## 2. 截面预处理

预处理在每个交易日的股票截面内独立完成，默认顺序如下：

1. MAD 去极值：以截面中位数为中心，将数值限制在 `中位数 ± 3 × 1.4826 × MAD`。
2. Z-score 标准化：减去截面均值后除以总体标准差。

两个步骤均可在研究工作台关闭。若截面 MAD 或标准差为零，系统保留原值，避免除零。预处理参数随实验保存，能够从任务详情复现。

## 3. 指标定义

| 指标 | 当前口径 |
| --- | --- |
| 覆盖量 | 进入检验的“证券 × 交易日”观测数 |
| IC | 每日截面因子值与下一日收益的 Pearson 相关系数 |
| Rank IC | 每日因子排名与下一日收益排名的 Pearson 相关，即 Spearman 相关 |
| IC 均值 | 所有有效日 IC 的算术平均 |
| IC 标准差 | 有效日 IC 的总体标准差 |
| ICIR | IC 均值除以 IC 总体标准差，当前不年化 |
| IC 为正比例 | IC 大于零的有效交易日占比 |
| IC 分布 | 将有效日 IC 按 `[-1, 1]` 固定为 10 个宽度 0.2 的区间；左闭右开，最后一区间包含 1；空值不计入 |
| 分组收益 | 每日按因子从低到高等数量分组，组内下一日收益等权平均 |
| 分组净值 | 各组日收益按 `净值 × (1 + 日收益)` 连乘，初值为 1 |
| 多空收益 | 最高因子组收益减最低因子组收益 |
| 多空净值 | 多空日收益连乘得到的净值，未使用现金或保证金模型 |
| 头部组换手率 | `1 - 相邻截面最高组交集数量 / 上一截面最高组数量` 的时间均值 |

## 4. 当前假设与限制

- 分组收益和多空收益未扣除佣金、印花税、冲击成本及滑点。
- 尚未模拟停牌、涨跌停、成交量约束和实际撮合。
- 尚未实现行业中性化、市值中性化及多因子相关性矩阵。
- 仓库样例数据是人工构造数据，只用于证明软件流程，不能形成投资结论。
- 指标适合课程版因子初筛，不等同于可直接实盘的策略回测。

## 5. 结果输出

结构化结果随 Run 保存，包括 IC 序列与分布、分组平均收益、分组净值序列、多空收益与净值序列、换手率和预处理参数。前端展示摘要指标、IC 分布、各组净值和多空净值曲线；独立 HTML 报告内嵌 IC／Rank IC、各组净值、毛／成本后多空净值 SVG 曲线及 IC 分布。各组净值图直接读取本次 Run 保存的 `group_nav`，不以平均收益重新推算。IC 空值以曲线断点表示，不替换为零。
