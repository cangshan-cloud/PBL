# 研究价格口径

任务有两种价格口径，创建时固定并随 Run 结果保存：

| 选项 | 计算价格 | 适用输入 |
| --- | --- | --- |
| `source_close`（默认） | CSV 中的 `close` | 已复权价格，或明确接受原始价格口径的研究 |
| `factor_adjusted` | 每行 `close × adj_factor` | 未复权 `close` 加数值复权乘数 |

价格类因子和下一交易日收益统一使用所选价格。换手率、市值和市盈率因子本身仍使用各自字段，但它们的下一日收益也按所选价格计算。任务对所选证券的全部读取行检查 `adj_factor`：缺失、非有限数或非正数会使任务失败，不作填充。

假设一只股票拆分前收盘价 100，拆分后原始收盘价 50，复权乘数从 1 变为 2。原始价格计算得到 −50% 的下一日收益；选择因子调整后，100 与 `50 × 2 = 100` 连续，收益为 0。这个例子由 `backend/tests/test_price_basis.py` 固定验算。

BaoStock 的 `adjustflag` 表示价格状态，并不是 `adj_factor`。适配器把它保存为来源元数据。若来源标记已经复权，单因子和多因子任务在**提交前**拒绝 `factor_adjusted`（HTTP 400，不创建任务）；执行阶段仍保留相同保护，避免旧任务或异常元数据绕过。适配记录明确为 `3`（不复权）时可选数值复权因子，但数据版本仍须有 `adj_factor` 列，且每行必须有有效乘数；没有整列时提交前即拒绝，不创建失败任务。来源状态畸形或不明确时拒绝因子调整。没有适配标记的其他来源，平台无法自动判断 `close` 是否已复权，导入者需要核对原始数据说明。所有证券须使用同一种复权定义和基准；不同口径的任务对比会给出警告。

研究工作台读取所选版本的适配来源状态。已复权或状态不明确时若选 `close × adj_factor`，页面会在提交前展示原因并禁用“运行研究”；改回“使用导入的 close”可继续。前端提示只改善交互，服务端提交前校验仍是最终防线。普通无适配状态的 CSV 不能由此判断是否已经复权。

研究工作台还读取所选版本的字段清单：若缺少 `adj_factor` 整列，选择 `close × adj_factor` 时即时提示并禁用按钮。列存在只证明结构满足最低条件，不代表每行乘数都有效，也不认证来源复权定义。

若 `adj_factor` 列存在但质量报告记录了空值，**未指定证券样本**的调整价研究也会在提交前拒绝，因为全量读取必然遇到缺失行。若明确指定证券，平台不能从全版本缺失总数判断所选证券是否受影响，因而允许提交并在 Worker 筛选证券后逐行校验；这避免把其他证券的空值误判到有效子集。该规则不处理复权乘数虽为正数但来源定义错误的情况。

新导入版本另记录 `missing_adj_factor_by_symbol`：仅列出乘数有空值的证券及行数。指定证券时，若其中任意证券在该明细中有缺失，页面和 API 会于提交前拒绝；完整证券子集仍可继续。旧版本若没有逐证券明细，不会由全版本总数猜测缺失归属，继续由 Worker 逐行校验。该字段不是价格复权来源的独立认证。

这项处理只校正价格连续性。当前收益检验仍未单独建模现金分红、停牌、涨跌停与实际可成交价格。

# 报告披露补充（2026-10-23）

对于新生成的 `factor_adjusted` 报告，如果数据版本的全量质量报告记录了缺失 `adj_factor` 行，即便本次只选完整证券并成功运行，归档报告与披露版交付副本仍提示：本次成功只证明所选样本通过乘数校验，不代表版本内其他证券也可用于调整价研究。使用原始导入价的报告不因无关的乘数空值添加此警告；既有不可变归档不回写。

普通导入 CSV 的新报告另外提示：平台的格式与已知日期异常检查不认证数据真实性、使用授权或完整交易日历。该通用来源限制与是否选择 `factor_adjusted` 无关；内置合成演示数据和封存历史包按各自专门口径披露。旧归档不回写，动态交付副本仍可附加当前披露。
