# Mac 浏览器只读产品验收（2026-10-21）

## 范围与环境

Mac + OrbStack 主栈，浏览器打开 `http://127.0.0.1:5173/`，以本机已初始化管理员账号登录。此次只查看已有版本、任务和报告，并发起一次现有报告的披露版下载；不上传文件、不发布版本、不提交新任务。Playwright CLI 包装器在当前沙箱中启动无输出，故改用应用内浏览器实点；宿主机本地 HTTP HEAD 返回 200。该浏览器验收不代表 Windows、其他浏览器或队长本人复测。
