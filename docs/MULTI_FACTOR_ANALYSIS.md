# 等权多因子合成

## 1. 课程版范围

平台支持从六个内置因子中选择 2—6 个因子进行等权合成。当前不提供机器学习权重、收益最大化权重或用户随意输入权重，避免在数据量和验证不足时引入过拟合。

## 2. 合成流程

对每个交易日依次执行：

1. 分别计算各成分因子的原始暴露值。
2. 每个因子独立执行所选的 MAD 去极值和截面 Z-score 标准化。
3. 以 `交易日 + 证券代码` 对齐，保留所有成分因子都有有效值的共同样本。
4. 各因子权重归一化后加权求和。当前等权模式下，N 个因子的实际权重均为 `1/N`。
5. 使用合成暴露值执行与单因子相同的 IC、分组和多空检验。

缺失因子值不会填零，因为填零会混淆“中性暴露”和“数据缺失”。系统在结果中同时记录每个成分的原始覆盖量和合成后的共同覆盖量。

合成前还要求每个成分在同一“交易日＋证券代码”上只有一条观测，且所有成分观测的因子值和下一日收益均为有限数；即使非法观测不在最终交集内，也会直接报错，避免预处理或对齐掩盖脏数据。共同样本中各成分的下一日收益标签必须一致（容许 `1e-12` 的浮点绝对误差）。重复观测或冲突标签会使任务失败并保留原因，不会悄悄用最后一条或第一个因子的收益替代。底层合成函数还拒绝非有限、负数或总和溢出的权重；正式产品仍只生成等权参数，不提供任意权重输入。共同样本按日期、证券排序后计算合成结果与相关矩阵，降低输入顺序对浮点结果的影响。

合成后的暴露值仍须为有限数；若极端但有限的原始值在合成或后续指标计算中溢出，任务会失败，不保存非法研究结果。

## 3. 复现信息

多因子实验绑定“等权合成规则”版本 `1.0.0`，并在实验参数中保存：

- 每个成分因子的标识和版本；
- 每个成分的回看窗口；
- 归一化后的实际权重；
- 数据版本、分组数和预处理参数；
- 代码版本及 Run ID。

重试任务会复制以上参数并生成新的实验和 Run，旧结果不会被覆盖。

## 4. 因子相关矩阵

平台在共同样本上计算每个交易日的成分因子 Pearson 相关系数，再对有效日期取算术平均。相关矩阵同时保存在结构化结果、展示于工作台，并纳入新生成的多因子 HTML 报告；无法计算的单元格显示为“—”。它用于识别高度重复的因子，不代表因果关系，也不自动证明某个因子带来独立增益或决定是否删除它。旧报告文件保持不可变，不会因本次展示改动而重写。

### 成分因子同样本 IC（2026-10-29 新 Run）

为帮助解释等权组合，平台现在额外保存每个成分因子在**所有成分共同有效的证券×信号日期**上的每日 Pearson IC 和并列平均名次 Rank IC，展示有效 IC 日数及信号日期数。计算时各成分先按其自身原始可用截面完成既定 MAD/Z 预处理，然后在共同样本上取值；所以表中数字反映**实际进入合成的成分值**，不是重新在交集上预处理的另一套口径。每日可计算值取算术平均，常数因子或收益导致的不可计算日不填零。

这张表进入结构化结果、工作台和**新生成的** HTML 报告。它是描述性诊断，不能把成分 IC 均值相加得到组合 IC，也不能据此声称某因子的独立增益、因果作用或未来表现。旧 Run 缺字段时页面显示未保存，归档报告不回写。实际私有历史包新 Run 的四因子和 242 日结果见[验收记录](HISTORICAL_COMPONENT_IC_QA_2026-10-29.md)。

任务中心现在也按已保存的 Run 展示同一张表。早于此字段的旧 Run 在任务详情明确显示“未保存”，不重新计算或改写其归档；新旧 Run 的实际浏览器回看见[任务中心验收](HISTORICAL_COMPONENT_IC_ARCHIVE_QA_2026-10-29.md)。

任务详情对保存了成分 IC 的 Run 提供原值 CSV 下载，包含完整 Run ID、因子键、IC/Rank IC 均值、有效 IC 日、信号日期数和共同覆盖量；空指标保持空单元格，旧 Run 不提供下载按钮。CSV 是已保存结果的摘要，不重新计算每日序列。实际下载验收见[CSV 验收](HISTORICAL_COMPONENT_IC_CSV_QA_2026-10-29.md)。

## 5. 限制

- 当前仅支持等权合成，尚未实现 IC 加权和滚动训练。
- 因子方向沿用定义本身，平台不会根据样本结果自动翻转方向。
- 合成结果仍未考虑交易成本、成交约束和行业、市值中性化。
- 如果任一成分所需字段缺失，任务在创建阶段被拒绝并列出缺失字段。
- 如果成分之间没有共同有效观测，任务进入失败状态并保存原因。
