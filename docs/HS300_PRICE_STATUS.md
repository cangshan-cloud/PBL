# 沪深 300 历史价格与可交易状态采集

本流程采集原始研究输入，不直接发布因子结论。已通过校验的 2024 年[成员快照](HS300_DATA_FEASIBILITY.md)是证券集合来源；原始文件存于 Git 忽略的 `data/real/`，不公开分发。

## 采集口径

`tools/fetch_hs300_prices.py` 按全年成员并集查询每只证券的日线，保留 `date/code/open/high/low/close/volume/turn/tradestatus/isST/adjustflag` 原始字段。请求 2023-11-01 至 2025-01-10：交易日历覆盖 2024 正式期之前 43 日、2024 年 242 日、之后 7 日；既满足至少 20 日预热，也包括 2025-01-02 的首个次年交易日标签。价格使用 BaoStock `adjustflag=1` 后复权；后续研究应选 `source_close`，不得再次复权。日期范围不等于每只证券都必然有完整有效行情，缺行和状态异常需逐日审计。

脚本逐只保存原始 CSV 检查点，重新运行时核查参数、成员快照 SHA-256 和已有文件结构后续采；成功完成才写入清单。校验器重算请求、日历和逐证券文件哈希，并核对每个正式成员交易日的分类统计。

```bash
python tools/fetch_hs300_prices.py --output-dir data/real/hs300_prices_2024
python tools/verify_hs300_prices.py data/real/hs300_prices_2024 \
  --members-dir data/real/hs300_members_2024
```

可用 `--codes sh.600519,sh.600606,sz.300750` 和新目录运行小样本探针；其输出明确只是部分证券，不可冒充全年完整价格包。

## 状态处理

BaoStock [日线字段说明](https://github.com/zxygithub/baostock/blob/master/docs/pythonAPI.md)将 `tradestatus=0` 定义为停牌，`isST=1` 定义为 ST。采集器不剔除停牌行，不填充缺失价格/成交量，也不以非空收盘价替代交易状态。实际小样本已观察到停牌行带有收盘价值，但成交量和换手率为空；研究层必须将该日视为不可交易。对某成员日若完全缺行，或状态字段为空，审计归为缺失/未知，不能默认为正常。

## 2026-10-13 全量实测

本机 BaoStock 0.9.4 对全年历史成员并集 328 只证券完成采集，共 95,776 条原始日线。采集日历覆盖 292 个交易日（2024 年前 43 日、2024 年 242 日、2025 年初 7 日），其首个 2025 年交易日为 2025-01-02。`verify_hs300_prices.py` 复算成员快照版本、请求/日历和 328 个证券文件的 SHA-256、日期及分类统计，全部通过。本机 `manifest.json` 的 SHA-256 为 `325e86b270a75ae45b72122f145fc6bf1a37a47d175e9a3aec7259f625296cfb`。

正式期 72,600 个成员交易日分类为：正常 72,514、停牌 86；缺行、未知状态、ST、零量、无效成交量、缺价格和缺换手率均为 0。分类之和等于成员交易日总数。**ST=0 只表示本次成员样本没有观察到 ST 日，不证明 ST 判定代码无需测试**；单元测试包含 ST 和未知状态反例。停牌行的非空 `close` 不能参与可交易候选或跨停牌的连续回看。

## 当前边界

本文件只说明原始数据采集与核验；完整不可变数据包发布、连续交易日因子窗口、t/t+1 收益、逐日排除报告仍待实现。现有后复权价格也可能随来源修订，不能把“有行情行”直接视作可交易或称为可执行交易收益。ST 状态的独立历史核验尚未完成。
