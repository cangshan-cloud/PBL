# 项目总览统计口径

项目总览是登录后的默认页面，用于快速说明平台当前资源、任务健康度和近期研究活动。

## 角色范围

- 管理员：展示平台全部任务和报告。
- 研究员：共享数据集和因子数量保持可见，但任务、报告、成功率及近期活动仅统计本人创建的研究。
- 只读用户：展示平台全部任务和报告，但不能创建或修改研究。

页面顶部的 `PERSONAL` 或 `GLOBAL` 标识会明确当前统计范围。

## 指标定义

| 指标 | 口径 |
| --- | --- |
| 已发布数据 | 状态为 `published` 的数据版本数量 |
| 草稿数据 | 尚未发布的数据版本数量 |
| 内置因子 | 六个可以直接选择的基础因子，不把合成规则重复计数 |
| 研究任务 | 当前角色范围内所有 Run 数量 |
| 成功率 | `success / (success + failed)`；等待、运行和主动取消不进入分母 |
| 研究报告 | 已成功生成 HTML 报告制品的 Run 数量 |
| 近期活动 | 按排队时间倒序显示最近五个有权查看的 Run |

当尚无成功或失败任务时，成功率显示为空值，而不是错误显示为 0%。

## 接口

登录后调用 `GET /api/v1/dashboard`。后端根据 Token 中对应的当前用户执行范围过滤，前端不能通过修改参数查看其他研究员的数据。
