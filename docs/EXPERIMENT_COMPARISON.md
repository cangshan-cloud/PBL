# 实验对比

## 1. 功能范围

实验对比用于横向查看 2—6 个已经成功的研究任务。它只读取任务保存的不可变指标产物，不重新计算因子，也不创建新的实验、任务或数据库记录。

对比页面展示：

- 有效观测、IC 均值、Rank IC、ICIR、IC 为正比例；
- 毛多空累计收益、成本后多空累计收益和头部组换手率；
- 每项指标相对首个所选任务的差值；
- IC、Rank IC、ICIR、成本后多空累计收益四项排名；
- 所有任务共有的**有效 IC**交易日数量，以及共有的实际多空分组日期数量。

首个选择的任务是对比基准。差值只表示数值差异，不代表统计显著性或因果关系。
排名只包含该指标确有有限数值的任务；缺失值不当作最后一名。
为兼容较早保存的结果，对比读取时会把非有限数值或无法转换为有限浮点数的异常整数视为该项缺失；原 Run 指标不改写。相关差值不计算，排名不包含该任务，CSV/HTML 显示空值或“—”。若成本后收益缺失或非有限，页面明确提示不能比较该项。

## 2. 可比性检查

后端会检查以下情况并返回警告：

- 数据版本不同：结果可能受股票池、日期和字段变化影响；
- 价格口径不同：复权处理不同会改变价格类因子和下一日收益；
- 分组数量不同：多空收益和换手率口径不一致；
- 没有共同有效 IC 日期：任务不具备同期横向比较基础；仅在序列中出现日期但 IC 为 `null` 不算有效证据。
- 成本假设不同或历史任务缺少成本后结果：净收益不可直接横向解释。
- 实际IC日期集合不同：即使有重叠，原始全区间指标也不是同期指标；
- 实际多空分组日期集合不同或没有共同日期：多空收益和换手率基于不同可分组日期，不能按同一时期直接比较；全同值或每日样本不足均可能导致跳过分组，但 IC 日期仍相同；
- 证券筛选、去极值、标准化参数或代码版本不同：结果变化可能来自实验口径。

页面显示每个任务有效 IC 起止日、有效截面数、证券筛选条件、价格口径、预处理参数和代码版本；CSV 导出还保存各任务实际多空分组日期数。共同日期数量仅用于诊断，系统不会自动在交集上重新计算历史指标。

出现警告时页面仍展示原始指标，但标记为“请谨慎解释”。当前版本不进行显著性检验、交易成本统一调整或不同日期区间的再计算。
导出报告区分毛多空收益与成本后多空收益：后者仅扣固定换手成本，两者都不模拟冲击成本和实际成交约束。

## 3. 接口与权限

请求：

```http
POST /api/v1/research/comparisons
Content-Type: application/json

{"run_ids": ["<run-1>", "<run-2>"]}
```

- 管理员和只读用户可以对比全部可见任务；
- 研究员只能对比本人创建的任务；
- 未完成、失败、取消、重复或缺少指标产物的任务会被拒绝；
- 请求只读，不改变任何历史研究记录。

## 4. 导出

完成对比后可以下载两种文件：

- `POST /api/v1/research/comparisons/export.csv`：每个任务一行，包含原始指标和相对基准差值。文件带 UTF-8 BOM，可直接用 Excel 打开。
- `POST /api/v1/research/comparisons/export.html`：自包含的中文对比报告，包含核心指标、排名、可比性检查和解释边界，可用浏览器打印为 PDF。

两个导出接口使用与对比接口相同的 JSON 请求体和权限规则。导出是即时生成的便携文件，不作为新报告存入数据库。

隔离 HTTP 回归会实际创建两条成功任务，调用对比接口并下载 CSV/HTML，核对新增的共同多空日期字段和导出内容；测试不访问现有运行数据库。
