# 实验对比

## 1. 功能范围

实验对比用于横向查看 2—6 个已经成功的研究任务。它读取已保存的不可变指标和受校验的逐股观测产物，不重新计算原始因子，也不创建新的实验、任务或数据库记录。

对比页面展示：

- 有效观测、IC 均值、Rank IC、ICIR、IC 为正比例；
- 毛多空累计收益、成本后多空累计收益和头部组换手率；
- 每项指标相对首个所选任务的差值；
- IC、Rank IC、ICIR、成本后多空累计收益四项排名；
- 所有任务共有的**有效 IC**交易日数量，以及共有的实际多空分组日期数量。
- 在共同有效 IC 日期上，依据各 Run 已保存的逐日序列重算 IC 均值、Rank IC 均值、ICIR 和 IC 为正比例。Rank IC 若为空会另行排除，并披露有效日数。
- 对均有逐股观测产物的新 Run，另取共同的“交易日 × 证券”键，按每个 Run 原先的预处理口径重新计算每日截面 IC、Rank IC、ICIR 与 IC 为正比例；披露共同观测、日期及下一日收益标签差异数。
- 对带时间切分的任务列出已保存的验证期起始日、有效 IC 日数和 IC 摘要；未切分任务显示缺失。全区间排名不转换成验证期排名。
- 若全部任务使用同一预设验证期起始日且观测产物齐全，再取**验证期共同日期 × 证券**键，按各任务原预处理口径重算严格同样本 IC；披露共同观测日数、观测数、收益标签差异和有效 IC 日数。

首个选择的任务是对比基准。差值只表示数值差异，不代表统计显著性或因果关系。
对比请求进行中若改变勾选任务或退出登录，前端会丢弃旧组合的晚到结果和错误；导出请求也不会在失效后触发旧组合文件下载。该保护不取消已经发给后端的只读请求。
页面和 HTML 的显示精度统一为：IC、Rank IC、ICIR 等非百分比连续指标 4 位小数，百分比 2 位，观测数不附加四位小数；差值显示正负号。CSV 保留原始数值用于进一步核对，不以页面四舍五入值替代。
排名只包含该指标确有有限数值的任务；缺失值不当作最后一名。
为兼容较早保存的结果，对比读取时会把非有限数值或无法转换为有限浮点数的异常整数视为该项缺失；原 Run 指标不改写。相关差值不计算，排名不包含该任务，CSV/HTML 显示空值或“—”。若成本后收益缺失或非有限，页面明确提示不能比较该项。

## 2. 可比性检查

后端会检查以下情况并返回警告：

- 数据版本不同：结果可能受股票池、日期和字段变化影响；
- 价格口径不同：复权处理不同会改变价格类因子和下一日收益；
- 分组数量不同：多空收益和换手率口径不一致；
- 没有共同有效 IC 日期：任务不具备同期横向比较基础；仅在序列中出现日期但 IC 为 `null` 不算有效证据。
- 成本假设不同或历史任务缺少成本后结果：净收益不可直接横向解释。
- 实际IC日期集合不同：即使有重叠，原始全区间指标也不是同期指标；
- 实际多空分组日期集合不同或没有共同日期：多空收益和换手率基于不同可分组日期，不能按同一时期直接比较；全同值或每日样本不足均可能导致跳过分组，但 IC 日期仍相同；
- 证券筛选、去极值、标准化参数或代码版本不同：结果变化可能来自实验口径。
- 混用切分与未切分、验证期起始日不同、参数与已存分段不符，或同起始日但有效 IC 日期集合不一致：验证期摘要不能直接归因于因子差异。仅同起始日时显示共同验证期有效 IC 日数。

页面显示每个任务有效 IC 起止日、有效截面数、证券筛选条件、价格口径、预处理参数和代码版本；CSV 导出还保存各任务实际多空分组日期数。原始全区间指标、差值、排名保持不变；共同日期摘要单独列示，不改写 Run。摘要没有统一逐股股票池或重新计算每日截面 IC，亦不重算多空收益、成本和换手。因此它是日期对齐诊断，不是完整的同样本重新研究。
对比结果还按任务披露 `dataset_source_kind`：`bundled_demo` 为内置演示数据，`historical_bundle` 为历史研究数据包，`imported_csv` 为导入 CSV。页面明确提示内置演示结果仅用于功能验收。这个类别表示平台入口和已存元数据，不认证行情真实性、数据使用许可或财务披露时点；普通导入文件不能仅凭“导入”称为真实数据。
对比候选列表同时显示数据版本号与 ID 前 8 位；生成对比后的“实际研究口径”表显示完整数据版本 ID。若两个任务的版本号文本相同但 ID 不同，应按不同数据版本解释，不能只看 `0.2.0` 等标签。
窄屏中完整 ID 可在单元格换行，宽口径表只在内部横向滚动，不要求整页横向滚动；价格、预处理和代码等后续列需按提示左右查看。

严格样本 IC 摘要与上述共同日期摘要分开。新任务把原始有效因子／次日收益观测保存在私有、gzip 压缩、SHA-256 校验的独立产物中，不进入常规任务列表响应。对比请求验证文件校验和后，只用所有选定 Run 共同的“日期 × 证券”键重新运行各自的截面预处理和 IC 计算。若有旧 Run 没有该产物，明确显示不可用，仍能查看原始指标和共同日期摘要。文件缺失或校验失败则拒绝严格对比，不以可能错误的数据继续计算。不同数据版本或价格口径的次日收益标签可能不同；系统计数并警告，但不会强制视其为相同收益。严格样本摘要也**不**重算分组、多空收益、换手或交易成本，不代表可交易回测或统计显著性。

旧 Run 缺少逐股产物时，顶部总体可比性降为“谨慎解释”，CSV/HTML 同步提示无法核对严格同样本 IC；这不否定旧 Run 的原指标，而是明确当前证据边界。无警告的“所列口径检查通过”也只表示列出的检查通过，仍属描述性回溯。

即使观测产物齐全，若共同“日期 × 证券”键为空，或交集样本使至少一个任务没有任何有效 IC 截面，严格样本摘要也标为**不可用**并解释原因，而非显示空指标却宣称重算成功。验证期严格样本采用同一规则；这类样本不足同时进入可比性警告。原始 Run 指标不受影响。

可计算的全区间与验证期严格样本摘要，还会以所选任务中**最少有效 IC 日数**标注证据基础：1—19 日为 `insufficient`（仅可计算、不能评价稳定性），20—59 日为 `limited`，60 日及以上为 `descriptive`。这些标签只提醒样本量，不是统计显著性检验、预测等级或选股推荐；不改变 `comparable` 的口径检查结果。页面、CSV、HTML 均显示最少日数和提示。

严格样本还分别披露每个任务的**交集样本保留率**：共同“日期 × 证券”观测条数 ÷ 该任务原全区间有效观测条数；验证期则除以该任务已保存的验证期有效观测条数。分子在同一比较内相同，分母可能不同；这不是共同股票数比例，也不是有效 IC 日比例。原分母缺失或为零时保留率为空，不填零。若交集条数大于某任务保存的分母，会提示产物口径不一致。保留率仅揭示样本缩小程度，不另设任意合格阈值。

另核对每个新 Run 的**逐股观测产物总条数**与已保存 `coverage`、切分日及以后产物条数与已保存验证期 `observation_count`。任一方向不等都会提示产物来源／分段口径异常，并在页面与 CSV/HTML 披露两侧计数；不静默修正原指标或观测产物。旧 Run 无逐股产物时对应核对计数为空。SHA-256 校验只证明文件与所登记校验和一致，不能单独证明指标与文件互相一致。

出现警告时页面仍展示原始指标，但标记为“请谨慎解释”。当前版本不进行显著性检验或交易成本统一调整。全区间严格样本 IC 与验证期严格样本 IC 分别列示；后者要求同一切分日、有效逐股产物以及验证期共同观测，否则明确标为不可用。两者都不重算可交易收益。不同因子的 IC 均值差异仍不等于因果或未来超额收益。
导出报告区分毛多空收益与成本后多空收益：后者仅扣固定换手成本，两者都不模拟冲击成本和实际成交约束。

## 3. 接口与权限

请求：

```http
POST /api/v1/research/comparisons
Content-Type: application/json

{"run_ids": ["<run-1>", "<run-2>"]}
```

- 管理员和只读用户可以对比全部可见任务；
- 研究员只能对比本人创建的任务；
- 未完成、失败、取消、重复或缺少指标产物的任务会被拒绝；
- 重复 Run ID 在 JSON 对比及 CSV/HTML 导出三个入口均返回 HTTP 400，不生成文件；
- 请求只读，不改变任何历史研究记录。

对比页进入时会刷新成功任务候选，并在页面保持打开期间每 2 秒更新一次任务列表；仍在执行的任务成功后无需切换页面即可出现。刷新候选不会清除当前勾选；未满两项时页面区分“正在加载”“任务仍在执行”和“还需完成一项”。这只是列表轮询，不自动生成对比或修改历史任务。

## 4. 导出

完成对比后可以下载 CSV、HTML 和 JSON；前两种由服务端导出：

- `POST /api/v1/research/comparisons/export.csv`：每个任务一行，包含完整数据版本 ID、数据版本 SHA-256 与版本号、原始指标、相对基准差值、共同日期 IC 与验证期 IC 摘要；末尾另列全区间及验证期严格样本 IC 摘要。文件带 UTF-8 BOM，可直接用 Excel 打开。外部脚本应按表头读取，不应依赖固定列序号。
- CSV 的 `dataset_source_kind` 与 JSON 同名字段使用机器可读枚举；HTML 任务溯源表在版本号下显示对应中文标签。旧 JSON 快照可能没有该字段，离线校验器保留兼容，但不能从缺失字段推断来源。
- `POST /api/v1/research/comparisons/export.html`：自包含的中文对比报告，开头按基准顺序列出完整 Run ID、实验名、完整数据版本 ID、数据版本 SHA-256、版本号和代码版本，并包含核心指标、两类严格样本 IC 摘要、原始排名、可比性检查和解释边界，可用浏览器打印为 PDF。

页面还提供“下载 JSON 快照”，直接保存当前已生成的结构化对比结果，保留任务顺序、完整 ID、数据版本 SHA-256、指标、警告、共同日期与严格样本摘要，适合程序化读取。文件在原有顶层字段之外增加 `export_format: "factorlab-comparison"` 和 `export_schema_version: 1`，供离线读取程序识别格式；这两个字段是客户端导出元数据，不参与研究计算。它不重新请求服务端、不创建持久报告，也不保证未来代码版本重新计算会得到相同结果；复现仍须依赖各任务的原始数据版本、参数和代码版本。

这里的校验和取自已保存的数据版本：普通 CSV 是导入文件字节 SHA-256；历史沪深 300 包是 `manifest.json` 字节 SHA-256，包内文件哈希需结合清单另行核对。校验和用于比对身份，不证明来源合法、文件仍可取得或因子结论可靠。

两个导出接口使用与对比接口相同的 JSON 请求体和权限规则。导出是即时生成的便携文件，不作为新报告存入数据库。
浏览器保存的 CSV、HTML 与 JSON 文件名按基准顺序包含各 Run ID 前 8 位，以便区分不同组合；短 ID 只是文件名提示，正式追溯仍以文件内完整 Run ID 和口径信息为准。
前端下载会在触发浏览器保存后短时保留 Blob URL，再释放临时资源；这只改善浏览器兼容性，不改变导出的服务端内容，也不保证网络失败时下载成功。
CSV 中所有文本单元格（包括末尾证据提示与不可用原因）若以公式触发字符开头或含危险前导空白，导出时会加单引号；摘要行也由 CSV 写入器处理逗号、引号与换行，避免列错位。JSON 对比结果和原始任务记录不变，数值指标不加前缀。

下载后可在离线环境用校验器核对文件：

```bash
python tools/verify_comparison_exports.py comparison.json --csv comparison.csv --html comparison.html
```

只给 JSON 时会检查格式版本、基准顺序、任务 ID 唯一性、数据版本 SHA-256 形状及基本计数；附加 CSV/HTML 时核对完整 Run／数据版本／校验和／代码身份、原始与共同日期 IC、共同日期数和风险提示。文件必须来自同一组、同一顺序的对比任务。校验器不重算因子、不检查原始行情真伪，也不提供加密签名或第三方可信时间戳。
HTML 的首张任务溯源表会按 JSON 顺序逐行核对角色、实验名、完整身份和数据哈希；仅把两个任务的哈希或 Run ID 互换，也会被拒绝。不应把该工具当作所有单元格的独立审计。
HTML 第二张原始指标表和第三张共同日期 IC 表的“IC均值”也按任务列核对，互换两任务数值会被拒绝。其余指标尚未逐格核验；四位小数显示值核对不等于独立复算。

隔离 HTTP 回归会实际创建两条成功任务，调用对比接口并下载 CSV/HTML，核对新增的共同多空日期字段和导出内容；测试不访问现有运行数据库。
同一 HTTP 旅程还模拟浏览器跨域 OPTIONS 预检及后续认证 POST，要求允许的本机来源可通过 CSV/HTML 导出，非白名单来源的预检被拒绝。它不等同浏览器下载事件测试；若只见 OPTIONS 而无 POST，应继续检查页面是否重载及浏览器网络状态，不能直接放宽 CORS 配置。
