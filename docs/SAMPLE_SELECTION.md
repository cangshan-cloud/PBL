# 研究样本与日期范围

## 1. 可配置参数

单因子和等权多因子任务都支持：

- 因子结果起始日期 `start_date`；
- 因子结果结束日期 `end_date`；
- 可选证券代码列表 `symbols`；
- 2—10 组的截面分组数量 `groups`。

证券列表留空表示使用数据集中的全部证券。输入中的空白项会被移除，重复证券代码按首次出现顺序去重。当前一次任务最多接收 1000 个证券代码。

## 2. 历史窗口口径

日期范围过滤发生在因子计算之后。系统先读取所选证券的完整数据并计算回看窗口，再仅保留因子日期落在起止日期内的观测。

普通 CSV 任务用**所选证券的日期并集**推断市场日历。某证券在该日历上缺少下一市场日价格时，不生成该日的前向收益标签；滚动因子若窗口中缺少市场日，也不生成该日因子观测。日期筛选不会绕过这项连续性要求。若全部所选证券同日缺行，系统没有独立日历可识别该日；历史沪深 300 专用任务另用封存交易日历。

例如研究从 2025-01-20 开始，20 日动量仍会读取 1 月 20 日之前的历史价格。若先截断数据再计算，会错误损失窗口历史，本平台不采用这种方式。

## 3. 边界规则

- 起始日期不能晚于结束日期。
- 所选证券必须至少有一个存在于数据集中。
- 实际证券数量不得小于分组数量，否则任务失败并记录明确原因。
- 日期过滤后必须至少保留一个有效因子观测。
- 多因子任务在各成分计算和日期过滤后，再取共同有效样本。

## 4. 复现

起止日期、原始证券列表、去重后的证券列表和分组数量保存在实验参数中。结构化结果与 HTML 报告还记录实际参与计算的证券数量和最终因子日期范围。
