# CHG-20261014-006：真实历史包公式与停牌标签独立抽样验算

- 日期：2026-10-14
- 类型：tool + research evidence
- 状态：implemented / verified
- 关联提交：与本记录同次提交

## 背景与目标

历史包研究已有端到端与审计下载验收，但四因子计算仍需要可由成员 C 亲自复做的、与平台研究代码分离的原始 CSV 抽样公式证据。本次限定两个证券日：正常标签和次日停牌标签。

## 决策过程

采用标准库脚本直接读取封存包的交易日历、当日成员和单证券源价格，不导入平台研究实现。选择一个正常样本检查四因子与收益，另选真实发生次日停牌的样本检查“有信号、无标签”的边界。没有把两点抽样扩张表述为整期独立回测，也不冒充成员 C 已完成其个人署名验收。

## 验证与结果

- 新增 3 项合成样本测试通过：四公式、正常次日收益、次日停牌无标签、非法代码和缺窗口行。
- 真实私有包 `2024-01-02/sh.600000` 与 `2024-03-19/sh.600584` 分别运行独立工具；与平台核心比较 8 个因子点，差异均小于 `1e-12`；正常次日收益及停牌缺失标签原因一致。
- 全量测试结果以本次提交前最终运行记录为准。真实包文件不纳入 Git。

## 风险、回退与未决事项

工具不验证封存包完整性，须先单独执行 `tools/verify_hs300_bundle.py`；它只覆盖两个样本，不验证历史成分来源、全部研究聚合或策略收益。成员 C 仍需自行复算并签名。可回退工具和材料，无数据库迁移。
