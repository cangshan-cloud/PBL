# CHG-20261026-004 报告归档检索与零匹配保护

## 问题与决策

报告中心已有预览和下载，但归档增多后只能逐项翻找。决定复用任务中心的轻量思路：仅对当前账号已取得的列表按研究名称或 Run ID 做忽略大小写的本地检索，保留服务端顺序。详情、风险提示、预览和下载必须绑定当前可见报告；零匹配时不能继续呈现旧报告。此功能不改变 API、数据授权或归档字节。实际执行者：Codex。

## 修改内容与对应位置

- `frontend/src/report-list.ts::filterReports`、`selectVisibleReport`：纯函数处理检索与当前可见选择；无匹配返回未选中。
- `frontend/src/main.tsx` 报告中心：新增检索框和命中计数，列表及选中报告改用可见集合；无匹配时显示明确提示并隐藏旧预览、下载和数据风险提示。
- `frontend/tests/report-list.test.ts`：覆盖名称、大小写 Run ID、原顺序、可见选择回退和零匹配。
- `docs/REPORT_SEARCH_BROWSER_QA_2026-10-26.md`、总索引及 A/B/C/D 四责任包：记录实点证据与边界。

## 验证结果与边界

前端 68 项测试和生产构建通过。隔离浏览器的 6 份旧归档验证 0/6、1/6、名称搜索与清空，零匹配时旧 iframe 与下载入口消失，控制台错误/警告 0。后端回归、金样本、台账与链接检查见本轮提交。未运行新研究，也未测试大规模列表性能、Windows 或队长本人产品操作；私有数据与用户修改的 Excel 未入库。
