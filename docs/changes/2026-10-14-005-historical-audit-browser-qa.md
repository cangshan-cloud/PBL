## 背景与目标

`CHG-20261014-003` 增加审计 CSV 下载，`CHG-20261014-004` 增加文件间核对工具；两者分别通过自动测试和本机直接函数调用，但尚未验证真实浏览器点击后取得的文件。目标是补齐这条交互链路，不污染已有 `fbl` 服务与数据库。

## 决策过程

使用 Playwright CLI 驱动真实浏览器、独立本地 SQLite、独立 8001/5174 端口及临时私有包副本。选择从网页注册、发布并运行真实历史任务，再点击两份 CSV 和复现包下载，而非只用 `curl`，因为后者无法覆盖按钮、浏览器 Blob 下载与文件名。复现文件保留在 Git 忽略的私有证据目录；临时数据库、报告与私有包副本验收后删除。未重建或修改当前 `fbl` 容器。

## 验证与结果

- Playwright CLI：管理员登录 → 注册 `hs300_2024_0375298bd2c8ac52` → 发布 → 历史模式运行；任务 `a0e06ff6-8f04-4d16-8ace-f26180eec587` 成功，有效观察 72,366。
- 实际点击“下载逐日审计 CSV”“下载无标签信号 CSV”“下载复现包”。浏览器下载目录生成 `historical-audit-daily-a0e06ff6.csv`、`historical-audit-unlabeled-a0e06ff6.csv`、`factor-run-a0e06ff6.json`；API 日志三个 GET 均为 200。
- 对上述三个浏览器下载文件运行 `tools/verify_historical_audit_exports.py`，返回 4 个因子、968 行逐日审计、32 条无标签信号，退出码 0。浏览器错误日志仅有 `favicon.ico` 404；无前端业务错误。
- 私有浏览器快照和下载文件在 `data/real/browser_evidence_20261014_auditcsv/`（Git 忽略）。隔离 API、Vite、浏览器进程已关闭；临时数据库、报告目录及 15 MB 包副本已删除。此数据副本只在临时环境中移除，原始封存包与既有 `fbl` 数据未删除。
