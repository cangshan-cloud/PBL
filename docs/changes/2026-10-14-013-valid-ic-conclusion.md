# CHG-20261014-013：结构化结论按有效 IC 截面判定

- 日期：2026-10-14
- 类型：research correctness + report wording
- 状态：implemented
- 关联提交：与本记录同次提交

## 背景与目标

结论模板把 `ic_series` 的日期总数写成“有效 IC 截面”，并用于 20/60 日证据门槛。研究计算允许某些日期 `ic=null`；因此缺失较多时，结论可能高估样本基础。历史报告还保留了“若使用当前成分股回溯历史”的通用风险句，与历史按日成分研究模式不贴合。

## 决策过程

以保存结果中 IC 为有限实数的日期为有效截面，与 IC 均值和分布图排除缺失值的既有计算口径一致；`null`、NaN、无穷和布尔值不计。缺失日期数单独披露，不填零。规则版本从 `1.0.0` 升至 `1.0.1`，便于识别动态结论变化；不重算指标、不覆盖旧 HTML 报告。历史报告风险仍保守，但应描述实际使用历史成员的事实和未核验边界，旧 CSV 模式保留原来的条件风险提示。

## 修改内容与对应位置

| 内容 | 位置 | 影响 |

| 历史/旧模式风险文案分流 | `backend/app/services/reports.py::build_report_html` | 报告解释与股票池实际口径一致 |

| 更新规则与历史包说明 | `docs/RESEARCH_CONCLUSION.md`、`docs/HS300_BUNDLE.md` | 导师能追溯口径变更 |
| 登记本次变更 | `docs/CHANGE_INDEX.md` | 统一索引 |

## 验证与结果

- `make test`：123 项通过。构造 100 个 IC 日期、仅 1 个有效值（其余含空值、NaN、布尔值）的用例被标为样本不足，文案披露 99 个不可计算日。
- `make golden`：固定手算样本的 6 个观测及 IC、分组和成本指标通过；研究计算本身未改动。
- 前次隔离容器下载的真实历史任务复现包有 242 个 IC 日期且 242 个有效值；该包的有效截面数量不会因本修正改变。此检查只读既有导出文件，未重跑任务。
- 更新前主 `fbl` 栈 26 条任务全为成功，无待执行任务。仅重建 API 和 Worker 后，Web/API/数据/账号/Worker 只读预检通过；既有任务的结论接口返回 `method.version=1.0.1`。主库仍为 26 条任务，26 份既有 HTML 报告全部通过存储校验和检查。

## 风险、回退与未决事项

此前已生成的 HTML 报告保持不可变，可能仍含旧结论或通用风险句；结论接口会按新规则动态呈现，需要引用者注明版本。这个修正只保证样本计数和文案准确，不是因子显著性检验或收益可交易性证明。Windows 环境未验收。
