# CHG-20261026-010 各组逐日净值 CSV 与复现包核对

## 问题与决策

IC 和多空曲线已可导出原值并与复现包核对，但各组净值图还只能目视。决定按结果中 `group_nav` 的既有组别及日期顺序输出长表 `run_id,group,date,nav`，只含毛净值，不从分组平均收益重算，也不补缺失日。同步扩展只读离线核对工具。实际执行者：Codex。

## 修改内容与对应位置

- `frontend/src/group-nav-export.ts`：将已存组别及逐日净值按原顺序展开为 UTF-8 BOM/CRLF CSV；无点只输出表头，字符串共用公式转义。
- `frontend/src/main.tsx`、`frontend/package.json`、`frontend/tests/group-nav-export.test.ts`：研究工作台各组净值图和历史任务详情提供下载；三项单测覆盖原序、完整 Run、数值、空态及转义。
- `tools/verify_series_exports.py`、`backend/tests/test_series_exports.py`：新增 `--group-nav-csv`，复用复现包结果 SHA 检查并逐行核对组别、日期和净值；加入错组、改值、换序、空态反例。
- `docs/SINGLE_FACTOR_ANALYSIS.md`、`docs/SERIES_EXPORT_VERIFICATION.md`、`docs/GROUP_NAV_CSV_BROWSER_QA_2026-10-26.md`、总索引和 A/B/C/D 四责任包：明确毛净值边界、命令与隔离浏览器证据。

## 验证与限制

旧成功历史 Run 的浏览器文件 5 组 × 242 日＝1,210 行，与复现包逐行一致；浏览器控制台无错误或警告。前后端回归、构建、黄金样例、台账和链接检查见本轮提交。未实点新任务工作台入口；文件及核对工具不证明数据真实、投资有效或实际可成交。私有下载和用户 Excel 修改均不入库。
