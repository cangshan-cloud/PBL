# CHG-20261026-013 新报告各组净值按日期对齐

## 问题与决策

网页图已按结果日期对齐，但新 HTML 研究报告的各组净值图仍借用最长组的日期、按各组数组下标绘制。若组间保存日期错位，报告会把不同日的净值画在相同横坐标。决定在交给既有 SVG 画图器之前，先用各组保存日期的并集对齐；缺日用空值断线。报告横轴明确标注“结果日期等距，非自然日间隔”。不新增独立市场日历、不改研究结果、CSV 或历史报告归档。实际执行者：Codex。

## 修改内容与对应位置

- `backend/app/services/reports.py::_align_dated_chart_series`：按已保存日期生成排序并集，并把各组数值映射到共同日期；缺少的日期保留为空值。
- `backend/app/services/reports.py::build_report_html`：各组净值图使用对齐后的日期与序列；`_svg_chart` 增加横轴及缺日语义说明，其 IC 和多空已有逐日空值断点规则不变。
- `backend/tests/test_reports.py::test_group_nav_report_aligns_dates_and_breaks_missing_day`：构造 Q1/Q2 不同日期，核对映射、SVG 断线和实际报告 HTML 调用。
- `docs/SINGLE_FACTOR_ANALYSIS.md`：补新报告口径，修复原指标表被说明段落截断的 Markdown 结构；本总索引及四份责任包登记本轮边界。

## 验证与未决事项

后端 292 项、前端 80 项、前端生产构建与黄金样例通过；台账和本地链接检查见本轮提交。没有启动容器、浏览器或新研究任务；错位日期是构造回归，不声称真实旧 Run 存在该问题。既有 HTML 报告字节与归档摘要保持不变，新逻辑只作用于以后生成的报告。若所有组均缺某市场日，日期并集不会显示该日；这不认证独立交易所日历，也不证明可成交收益。队长本人产品实测仍待完成。
