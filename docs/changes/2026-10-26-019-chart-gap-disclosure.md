# CHG-20261026-019 网页曲线显式列出内部全线空缺日期

## 问题与决策

CHG-20261026-017 已实现已知缺日断线，但长日期轴上单个断点可能不易肉眼识别。决定在网页 IC、多空和各组净值图添加可展开日期提示，只覆盖两个有效点之间、该图所有显示线都无有限数值的已知日期。边缘无值、仅个别线无值不计入，避免将普通样本起止和组间不齐误称为“全线空缺”。不推断停牌、缺行情或未记录交易日，不改研究公式、结果对象、CSV、新旧 HTML 报告或主服务。实际执行者：Codex。

## 修改内容与对应位置

- `frontend/src/chart-series.ts::interiorAllMissingDates`：基于已对齐的线段索引找第一/最后有效点，仅返回其间没有任何线点的已知日期。
- `frontend/src/main.tsx::KnownGapNotice`、`NavChart`、`IcSeriesChart`：三类网页图复用折叠提示和限制文案；没有内部全线空缺时不显示。
- `frontend/src/layout.css::.chart-gap-notice`：提示与展开日期的窄屏折行、限高滚动样式。
- `frontend/tests/chart-series.test.ts`：覆盖诊断独有日期、部分线有值、边缘缺值、无值/单点等边界。
- `docs/SINGLE_FACTOR_ANALYSIS.md`、本索引及 A/B/C/D 四责任包：记录显示口径、代码位置和验收归属。
