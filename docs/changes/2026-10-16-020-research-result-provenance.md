# CHG-20261016-020：研究工作台结果归属防误读

- 日期：2026-10-16
- 类型：产品结果展示正确性与验收
- 状态：Mac 隔离浏览器验证通过；私有历史审计下载浏览器验证待做
- 关联提交：与本记录同次提交；如提交受阻，以工作树状态为准

## 背景与决策过程

继续开发时核查课程演示路径，发现工作台结果绑定的是“最近运行任务”而不是“当前表单配置”。若研究员先运行动量，再选反转或改变分组数，原指标仍显示在新参数下方；未运行时以五个 `0.00%` 占位。这是研究解释风险，优先级高于再增加视觉装饰。决定把实际提交参数构造与展示配置键合一，仅在配置一致时显示任务结果，并把 Run 与数据版本显式列出。既有历史审计按钮还引用任务中心选中项，决定改为工作台当前历史 Run；没有历史私有包浏览器证据，因此保留未验边界。

## 修改内容与代码位置

| 内容 | 对应位置 | 影响 |
| --- | --- | --- |
| 提交参数与结果绑定 | `frontend/src/main.tsx` 的 `researchParameters`、`researchConfigKey`、`runResearch`、工作台结果区 | 参数变化隐藏旧结果；新任务绑定提交时配置；显示 Run ID |
| 空值与分组标签 | `frontend/src/main.tsx` 工作台指标、分组图和任务详情 | 未计算不显示假零；`Qn − Q1` 随分组数变化；任务详情不固定“五组” |

| 验收与演示门槛 | `docs/RESULT_PROVENANCE_BROWSER_QA_2026-10-16.md`、`docs/FINAL_REHEARSAL_CHECKLIST.md`、`docs/PRD_ACCEPTANCE_MATRIX_2026-10-14.md` | 保留运行 ID、交互步骤、未验边界 |
| 四责任包与总索引 | `docs/member-deliverables/` A/B/C/D、`docs/CHANGE_INDEX.md` | 记录实际执行者及责任对应结果 |

## 验证结果

前端生产构建、后端 191 项测试、固定六观测黄金验算通过；隔离浏览器验证初始空态、动量运行、切换反转后隐藏旧结果、三分组新任务与动态标签；控制台错误 0、警告 0。完整 Run ID 和步骤见验收文档。实际执行者：Codex。

## 风险与回退

历史审计下载修正没有私有历史包浏览器实测，不能标为完整验收。结果配置键只绑定本次浏览器会话中的工作台任务，不替代后端不可变任务参数与复现 JSON；页面刷新后仍应从任务中心查历史结果。回退可撤销本次前端改动及文档，但会恢复旧结果误读风险，不建议在课程演示前回退。
