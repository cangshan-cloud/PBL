# CHG-20261014-015：多因子共同样本标签一致性与确定性

- 日期：2026-10-14
- 类型：research correctness + tests
- 状态：implemented / verified on macOS
- 关联提交：与本记录同次提交

## 背景与目标

多因子合成原来用字典索引各因子观测，同一因子重复的日期/证券会被最后一条静默覆盖；共同样本的下一日收益直接取第一个因子，没有检查其他因子的标签是否相同。相关矩阵遍历无序集合，也使浮点求和顺序依赖进程哈希种子。这些行为不符合可复现研究和错误显式暴露的要求。

## 决策过程

在预处理后建索引时拒绝重复键；在共同样本上要求所有因子下一日收益与首个成分一致，容许 `1e-12` 绝对误差以兼容极小浮点差异。拒绝非有限的首个标签。合成与逐日相关计算都遍历排序后的日期/证券键，不改变因子权重或公式，也不覆盖既有任务。只在共同样本检查跨因子标签，因为未进入合成的非共同观测不影响本任务收益。
