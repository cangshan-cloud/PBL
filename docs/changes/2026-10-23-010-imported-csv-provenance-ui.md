# CHG-20261023-010 普通 CSV 来源边界前移到页面

## 问题与决策

CHG-009 只让新报告披露普通 CSV 的来源/授权/日历认证边界，研究员在选择数据版本时仍可能把质量检查“通过”误读为来源已认证。决定在数据集页、研究工作台所选版本及报告中心所选归档旁给出一致的**非阻断**提醒；不改变任务准入规则。实际执行者：Codex。

## 修改内容与位置

- `frontend/src/dataset-alerts.ts::importedCsvProvenanceNotice`：基于版本质量报告的 CSV 字段清单判定普通导入 CSV；排除已识别内置合成演示版本及封存历史包，旧版本缺少必要元数据时不臆测。
- `frontend/src/main.tsx`：数据集页提示普通 CSV 质量检查边界，研究工作台针对所选版本提示，报告中心仅在数据版本 ID 与 SHA 同时匹配时展示提醒，并注明旧归档未改写、交付副本附加披露。
- `frontend/tests/dataset-alerts.test.ts`：覆盖普通 CSV、旧元数据、内置演示版本和封存历史包的分支。
- `docs/CHANGE_INDEX.md`、开发计划、PRD 验收矩阵及 A/B/C/D 四责任包：同步本轮决策和验收范围。

## 验证与边界

前端 **51 项**测试和生产构建通过；变更台账与 `git diff --check` 通过。本轮未更新容器或实点浏览器，新提醒不能代替导师/队长对原始数据来源及授权的人工核实。旧归档仍按原校验和提供，页面提醒与动态交付副本不是旧归档字节的变更。
