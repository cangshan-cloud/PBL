# CHG-20261014-016：历史审计核对增加结果摘要验证

- 日期：2026-10-14
- 类型：evidence integrity + tests
- 状态：implemented / verified
- 关联提交：与本记录同次提交

## 背景与目标

独立审计工具原本核对两份 CSV 与复现 JSON 内的审计字段，却未使用复现包提供的 `result_sha256`。如果 JSON 中仅有非审计指标被意外改动，CSV 仍与审计字段一致，工具会虚报通过。需要先校验整个结果对象。

## 决策过程

复用后端 `build_reproducibility_bundle` 已定义的规范序列化口径：UTF-8、非 ASCII 原样、键排序、无多余空格、拒绝 NaN。独立 CLI 只依赖标准库，不导入后端，避免“同一代码自证”。缺失、格式错误或不匹配的摘要均拒绝；通过后再做原有逐行与汇总核对。不增加新服务接口，也不重新生成历史报告。

## 修改内容与对应位置

| 内容 | 位置 | 影响 |
| --- | --- | --- |
| 重算并核对复现包 `result_sha256` | `tools/verify_historical_audit_exports.py::verify_exports` | 非审计指标变化亦可被发现 |
| 完整摘要夹具、非审计字段篡改、缺摘要及原有审计失败回归 | `backend/tests/test_historical_audit_exports.py` | 防止误报通过 |
| 更新工具说明与可信边界 | `docs/HS300_BUNDLE.md` 的“审计 CSV 导出” | 不把普通摘要误称为签名 |
| 登记变更 | `docs/CHANGE_INDEX.md` | 可追溯 |

## 验证与结果

- `make test`：128 项通过。
- 对前次真实历史任务下载的复现 JSON、逐日与无标签 CSV 重新运行独立工具：4 因子、968 行逐日审计、32 条无标签信号，通过新增摘要校验。
- 本次只修改离线核对工具、测试与文档；主 `fbl` 服务和 26 条任务不需重建或更改。

## 风险、回退与未决事项

SHA-256 摘要没有签名或密钥，攻击者可协调修改结果、CSV 和摘要，因此本工具仍不是来源真实性证明。它也不验证报告文件或私有行情原始数据。旧版缺少结果摘要的临时手工夹具会被拒绝；正式 API 复现包已有该字段。Windows 尚未单独实测。
