# CHG-20261018-004：真实小样本验证期严格对比与导出复核

## 背景与决策

本机已有 2024 上半年 BaoStock 私有快照，原只读脚本能核对五因子覆盖与分组日期，但新增的时间切分、共同证券×日期严格样本、产物计数和对比导出尚未在这份真实样本上复跑。决定扩展原校验脚本，在内存 SQLite 与临时数据目录中对 20 日动量和 5 日反转预设同一验证期起始日 `2024-04-01`，不写入日常数据库，不更新或公开原始行情文件。

## 本机结果与解释

- 私有 CSV 与采集清单相符：SHA-256 `958e7bdcd5f6269d4e9630f586b91814b40019c043d610b344bd7d5ac381b652`，1,170 行、10 股，实际日期 2024-01-02 至 2024-06-28。原五因子有效观测和分组日期均保持既有数值。
- 新增同起点切分：共同有效 IC 日 96；验证期共同有效 IC 日 58。全区间严格交集 960 条，验证期严格交集 580 条；两段的次日收益标签差异均为 0。
- 动量全区间／验证期原观测 960／580，严格交集保留率均 100%；反转 1,110／580，全区间保留率约 86.49%，验证期 100%。两任务全区间及验证期的指标观测数与校验产物条数一致。
- 验证期严格样本最少有效 IC 日为 58，证据等级 `limited`。这是有限样本的描述性软件检验，不是显著性、前瞻性或投资收益证明。
- CSV 两条核心行的 Run ID、有效观测、验证期有效 IC 日与 API 对比结果一致；HTML 包含验证期严格交集 580 条。导出检查没有替代完整视觉排版审查。

`.venv/bin/python tools/verify_real_a_share_sample.py`、后端 209 项测试和六观测手算黄金验算通过。前端代码未改，本轮未重跑前端测试或浏览器。数据为人工固定 10 股、短区间；存在选择偏差、价格后复权来源差异，PE 披露时点仍未独立核对，不能称为全市场回测。原始数据仍为 Git 忽略的私有本机文件，未重新联网采集。实际执行者：Codex；四人责任包是代执行记录，不代表成员本人签收。
