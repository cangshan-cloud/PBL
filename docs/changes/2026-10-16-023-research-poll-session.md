# CHG-20261016-023：研究轮询的会话隔离

- 日期：2026-10-16
- 类型：产品异步状态可靠性
- 状态：Mac 本机自动测试通过；浏览器与远端 CI 待核对
- 关联提交：与本记录同次提交

## 背景与决策过程

工作台研究任务以 POST 后的 500 ms 轮询更新进度。此前退出登录会清空页面状态，但未让仍在等待或请求中的旧轮询失效；旧响应可能随后把前一账号的任务状态重新写入 React 状态，完成时还会触发列表刷新。这是会话切换时的误展示风险。决定以递增的前端会话序号隔离旧轮询，并把轮询控制抽为可测试函数；退出仅停止本浏览器对该任务的跟踪，不向后端发送取消命令。

## 修改内容与位置

| 内容 | 位置 |
| --- | --- |
| 等待后、请求响应后分别检查会话是否仍有效，失效即停止且不发布旧结果 | `frontend/src/research-task.ts::pollResearchTask` |
| 提交响应和异常／收尾状态也按会话序号保护；退出时使旧会话失效并恢复登录按钮可用 | `frontend/src/main.tsx::runResearch`、`logout` |
| 覆盖正常完成、等待中退出、请求中退出三个时序 | `frontend/tests/research-task.test.ts` |
| 前端测试入口包含新文件 | `frontend/package.json` |
| 决策、验收索引及责任包 | 本文件、`docs/CHANGE_INDEX.md`、`docs/PRD_ACCEPTANCE_MATRIX_2026-10-14.md`、`docs/member-deliverables/` |

## 验证与边界

实际执行者：Codex。Mac 上前端 12 项、生产构建、后端 191 项和固定六观测黄金验算通过。未重新做浏览器多账号切换、Celery／Compose 或 Windows 部署。前端停止跟踪不等于取消服务器任务；已创建的任务仍按服务端队列与权限处理。其他页面的短请求并未在本轮统一加会话隔离，需独立审查；不宣称整个前端所有异步竞态已消除。

## 回退

可回退轮询抽离与会话序号，恢复旧轮询行为；但会重新暴露退出后晚到结果写回的风险。后续若改为统一请求取消机制，须明确 POST 已送达而客户端中断时任务可能仍存在的语义。
