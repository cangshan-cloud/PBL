# CHG-20261027-003 网页每日 IC 图并列 Rank IC

## 问题与决策

同一个 Run 已保存每日 IC 和 Rank IC，逐日 CSV 与新 HTML 报告也可核对两者，但研究工作台、任务中心曲线仅展示 IC。为减少图与报告之间的切换，决定在原图共轴绘制两条独立序列；各自缺值独立断线，不以零替代，图例显示各线最后可绘制值。零基线和日期轴沿用原口径，IC 分布仍只统计 IC。实际执行者：Codex。

## 修改内容与对应位置

- `frontend/src/chart-series.ts::icChartLines`：把保存结果中的 IC、Rank IC 映射为两条独立曲线，空值转为不可绘制点；复用原日期对齐与断线逻辑。
- `frontend/src/main.tsx::IcSeriesChart`：双线、双图例、共同纵轴范围，分别统计两类有效值/缺值；工作台与任务回看共用此组件。
- `frontend/tests/chart-series.test.ts`：覆盖两序列错位空值、独立末值和已知日期轴。
- [隔离浏览器验收](../RANK_IC_WEB_CHART_QA_2026-10-27.md)、`docs/SINGLE_FACTOR_ANALYSIS.md`、本索引、A/B/C/D 四责任包：记录范围、指标解释和验收边界。
