# CHG-20261026-007 每日 IC 与 Rank IC 原值 CSV 导出

## 问题与决策

平台已有每日 IC 曲线与复现 JSON，但研究人员用表格逐日复核时还需手动抽取结构化序列。决定只把已保存的 `ic_series` 导出为 `run_id,date,ic,rank_ic` CSV：完整 Run ID 随每行保存、沿原序列保留全部日期、空值留空、负值和精度不变；不重算或把空值填零。成功历史任务和当前研究结果共用导出函数。实际执行者：Codex。

## 修改内容与对应位置

- `frontend/src/ic-series-export.ts`：生成 UTF-8 BOM、CRLF 和带短 Run 文件名的全量 CSV；数值使用原始序列化文本，非有限数值按空值处理。
- `frontend/src/csv-cell.ts`、`daily-coverage-export.ts`：抽出共用 CSV 单元格转义；字符串防电子表格公式注入，数值负号保持数值。原逐日样本诊断 CSV 的接口与输出保持兼容。
- `frontend/src/main.tsx::IcSeriesChart`、任务详情：当前结果和历史 Run 都提供“下载每日 IC CSV”，统一保存同一结果对象中的原序列。
- `frontend/src/layout.css`、`frontend/tsconfig.json`、`frontend/package.json`：导出控件布局；因 Node 的直接 `.ts` 测试需要显式源文件扩展名，在前端 `noEmit` TypeScript 配置启用对应导入选项；纳入新测试。
- `frontend/tests/ic-series-export.test.ts`：核对负值原精度、日期/Run、空值、空序列和恶意文本防公式注入；原逐日诊断导出测试继续运行。
- `docs/IC_SERIES_CSV_BROWSER_QA_2026-10-26.md`、总索引和 A/B/C/D 四责任包：记录隔离下载证据及未测边界。

## 验证结果与边界

前端 72 项测试与生产构建通过。隔离浏览器从旧成功 Run 下载 242 行历史 IC CSV，Run/列数/负值及文件摘要已核；下载后 Playwright 会话意外结束，仅可从留存控制台日志确认无错误/警告记录。研究工作台入口和与复现 JSON 的逐行独立比对未做浏览器验收。后端全量回归、金样本、台账与链接检查见本轮提交。导出不是显著性检验、数据来源认证或新研究结论；私有衍生文件和用户修改的 Excel 未入库。
