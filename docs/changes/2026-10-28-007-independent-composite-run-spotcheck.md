# CHG-20261028-007 历史四因子合成与实际 Run 逐股独立抽样核对

## 问题与决策

已有单证券源 CSV 公式手算和同代码全期重算，但两者之间缺少“独立公式 → 实际 Run 逐股产物”的自动对照。决定对代表性交易日的完整 300 成分截面独立重算四因子、MAD/Z 分数与等权合成，严格比较私有观测产物中的证券键、因子值和次日收益；不引入另一个数据源，也不把三日抽样宣称为全年认证。实际执行者：Codex。

## 修改内容与对应位置

| 修改 | 位置 | 理由 |
| --- | --- | --- |
| 独立单日截面验算器、可选产物 SHA-256 闸门 | `tools/verify_historical_composite_spotcheck.py::verify`、`_standardize` | 对照真实 Run 的逐股产物，避免只对照项目算法自身 |
| MAD/Z 正例及篡改、缺证券反例 | `backend/tests/test_historical_composite_spotcheck.py` | 固定工具的失败边界 |
| 真实三日证据及适用边界 | `docs/HISTORICAL_COMPOSITE_INDEPENDENT_SPOTCHECK.md` | 供课程验收追溯 |
| 本条索引与 A/B/C/D 责任包 | `docs/CHANGE_INDEX.md`、`docs/member-deliverables/` | 同步团队材料 |

## 验证与未决事项

新工具对 `2024-01-02`、`2024-03-19`、`2024-12-30` 的 300/299/299 条有效观测逐股通过；后两日各有一条有明确排除理由。最大合成值差 `8.88e-16`，收益差 0。构造反例单测通过；后端全量回归、黄金核对、台账与链接检查随本提交执行。只验证三日，不保证全年或原始数据权利与真实性；私有包和观测产物继续不入库。用户改动的 Excel 不处理。
