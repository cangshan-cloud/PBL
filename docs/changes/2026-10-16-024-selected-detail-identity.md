## 背景与决策过程

任务中心和报告中心会按当前选择异步加载日志、规则结论与 HTML 预览。切换选择或退出时，先前请求可能晚到；即使下一轮请求马上开始，旧内容还可能短暂出现在新标题下面。上一轮只处理工作台研究轮询，不覆盖这些详情。决定双层防护：请求的 effect 清理后不再写状态；已缓存内容只在其 Run ID 等于当前选择时展示。这样不改 API 或后端存储，也不把“加载中”误称为另一任务的详情。
