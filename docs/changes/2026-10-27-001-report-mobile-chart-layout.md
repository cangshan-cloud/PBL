# CHG-20261027-001 新报告窄屏图表与长复现信息布局

## 问题与决策

对 CHG-20261026-020 的新报告断点提示做浏览器补验时发现：390px 视口下 SVG 刻度和日期缩得过小，长版本号把复现信息双列卡片撑出整页。决定只调整新生成 HTML 的展示层：图表保留屏幕最小可读宽度并在图内滚动，打印时恢复自适应；长元信息允许换行，窄屏改为单列。研究结果、日期轴、计算公式和旧归档均不改变。实际执行者：Codex。

## 修改内容与对应位置

- `backend/app/services/reports.py::_svg_chart`：图表 SVG 包入 `.chart-scroll`；横轴口径文案加入窄屏横向滚动说明。
- `backend/app/services/reports.py::build_report_html`：CSS 设置图内滚动与 `560px` 屏幕最小宽度、打印覆盖；元信息卡片长值折行，600px 以下改单列并收窄页面留白。
- `backend/tests/test_reports.py`：检查新 HTML 的滚动结构、说明文案、打印及元信息响应式规则，保持原断线测试。
- [浏览器记录](../REPORT_GAP_MOBILE_QA_2026-10-27.md)、`docs/SINGLE_FACTOR_ANALYSIS.md`、本索引及 A/B/C/D 四责任包：登记发现、复验数据和边界。

## 验证与未决事项

合成报告在 390px 浏览器中整页无横向溢出，图内 `320/560px` 可局部滚动 `240px` 到末尾日期；断点提示可展开。全量测试与台账检查见本轮提交。临时静态服务仅 favicon 404。真实任务的新报告浏览器/打印实点和队长本人产品实测仍待完成；不回写旧报告归档。
