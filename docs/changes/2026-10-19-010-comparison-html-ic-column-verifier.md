# CHG-20261019-010 HTML 对比 IC 指标逐任务核对

## 问题与决策

CHG-20261019-009 已将 HTML 溯源身份绑定到任务行，但离线校验器仍只查找原始 IC 文本是否出现在整份报告，且未核对共同日期 IC 的具体列。两个任务的 IC 值若互换，原数值都还在报告中，可能误判通过。决定在现有标准库 HTML 解析路径中，按对比任务顺序核对“核心指标（原始全区间）”和“共同日期 IC 摘要”两张表的 IC 均值列；不改变服务端报告、JSON/CSV 或研究计算。

## 修改位置

- `tools/verify_comparison_exports.py`：解析 HTML 各表的 tbody 行；首表仍核对任务身份，第二、三表分别定位唯一“IC均值”行，并逐列对照 JSON 中原始与共同日期 IC 的显示精度。缺失值按报告的“—”口径处理。
- `backend/tests/test_comparison_export_verifier.py`：新增原始 IC 与共同日期 IC 的双列互换反例；保留合法三格式及身份错配反例。
- `docs/EXPERIMENT_COMPARISON.md`、`docs/CHANGE_INDEX.md`、A/B/C/D 四责任包：说明新检查和边界。实际执行者：Codex。

## 验证与边界

定向测试通过，后端全量 214 项通过；上一轮浏览器实际下载的同组 JSON/CSV/HTML 在新规则下仍返回 2 任务、2 警告、CSV/HTML 均通过。

本轮只逐列核对两种 IC 均值；HTML 其余指标尚未逐单元格审计。显示值采用四位小数，所以比较的是报告展示结果，不是未舍入原值。校验器仍不复算因子、验证市场数据来源或提供防同步篡改的签名。
