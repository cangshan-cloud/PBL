# CHG-20261014-004：历史审计导出的独立一致性核对

- 日期：2026-10-14
- 类型：tool + evidence
- 状态：implemented / verified
- 关联提交：与本记录同次提交

## 背景与目标

历史审计 CSV 下载已经实现，但团队成员拿到复现 JSON 与两份 CSV 后缺少无需私有行情、无需启动平台的核对方法。本次把真实包试算中的人工对账固化为跨 Mac/Windows 的标准库 CLI。

## 决策过程

考虑在平台内生成第三份校验报告，以及独立 CLI。前者会重复信任同一运行进程且增加接口；选择独立 CLI 从三个已下载文件核对行和汇总，便于成员独立提交验收材料。核对范围明确限定为**文件间一致性**，不是独立重算因子或来源鉴定，不宣称防篡改真实性。

## 修改内容与对应位置

| 内容 | 位置 | 影响 |
| --- | --- | --- |
| 读取复现 JSON 与两份 CSV，校验列、逐行、逐日总数、无标签数量并返回非零失败码 | `tools/verify_historical_audit_exports.py::verify_exports`、`main` | 不依赖私有行情或后端包，可供成员独立检查 |
| 正常、CSV 内容改动、JSON 汇总不一致与无审计场景测试 | `backend/tests/test_historical_audit_exports.py` | 防止校验器自身回归 |
| 使用说明、真实包检查结果及声明边界 | `docs/HS300_BUNDLE.md` 的“审计 CSV 导出” | 说明如何纳入验收材料 |
| 变更登记 | `docs/CHANGE_INDEX.md` 的变更表 | 保持追溯 |

## 验证与结果

- 私有历史包重算四因子审计后，在临时目录生成与下载接口同内容的 CSV 和复现 JSON；`verify_exports` 返回 `factors=4, daily_rows=968, unlabeled_rows=32`，所有行与汇总一致；逐日候选合计 290,400，有效收益合计 289,576，无标签原因均为次日停牌。
- 三项新增单元测试通过，覆盖一致、篡改和无审计输入；全量测试结果以本次提交前最终运行记录为准。
- 本次未在真实浏览器点击新下载按钮，也未重建既有 OrbStack 容器。CLI 对复现文件自身真实性和数据来源不作保证。

## 风险、回退与未决事项

如果 JSON 与 CSV 同时被协调篡改，文件间一致性检查仍可能通过；正式审计须另核对任务 ID、数据版本及 SHA-256，并在具备私有数据包时独立重算。CLI 为只读工具，回退只需移除工具及文档，不涉及数据库迁移。
