## 背景与目标

队长要求以后每次修改项目内容时，记录修改内容、对应代码位置和决策过程，并由一个 Markdown 总索引指示。本次只建立记录制度，不据此批准或实现任何扩展功能。

## 决策过程

采用“一个总索引 + 每次变更一条 Markdown 记录 + 一个模板”的结构。相比把所有细节堆在单一长文件中，这样可以让索引保持可扫描、单次变更与同次代码提交相邻；相比只依赖 Git 提交说明，它能保存方案取舍、验证和未决事项。历史修改以 `5d081b4` 为基线，不伪造过去逐次讨论过的决策过程。扩展项仍待 grill-me 访谈确认，当前建议不等于批准实施。
