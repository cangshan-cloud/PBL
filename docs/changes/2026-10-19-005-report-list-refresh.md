# CHG-20261019-005 报告中心自动刷新与准确空态

## 问题与决策

报告中心此前只在进入时请求一次列表；若另一标签随后完成研究，新报告不会出现，且首个请求返回前可能短暂显示“暂无报告”。决定沿用对比页已验证的轻量轮询：仅停留在报告视图期间每 2 秒刷新报告列表，离开即清理定时器；保留已选报告 ID 和预览，不因新报告到来而抢切。加载期改用明确提示。

## 修改位置

- `frontend/src/main.tsx`：报告视图进入时标记加载并请求列表，停留期间轮询，离开清理定时器；导航即时设置加载态，空态按状态呈现。
- `frontend/src/report-list.ts`、`frontend/tests/report-list.test.ts`：覆盖加载中、真正空档与已有报告的提示边界。
- `frontend/package.json`：纳入新增前端测试。
- `docs/CHANGE_INDEX.md`、A/B/C/D 四责任包：记录决策与实测。

## 验证与边界

前端 32 项测试和生产构建通过。隔离 Mac 应用内浏览器使用同一研究员的两个标签：报告中心保持打开，另一标签先后完成 20 日动量、5 日反转任务；两份报告均自动出现在列表且第一份 HTML 预览正常。第二份出现后预览仍为用户原先选中的第一份。CLI Playwright 因离线 npm 缓存缺包不可用，改用应用内浏览器复测。

这只验证单机演示数据和两标签交互，不代表多用户并发性能、真实样本报告或 Windows 验收。轮询增加少量列表请求，不改变报告生成、权限或研究计算。实际执行者：Codex。
