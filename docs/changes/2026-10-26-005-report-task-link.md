# CHG-20261026-005 报告身份展示与同 Run 任务定位

## 问题与决策

报告归档已支持名称或 Run ID 检索，但列表原来只显示名称、版本和时间。多个同名、同版本报告难以区分，也不便从报告核对产生它的任务。决定在列表展示短 Run ID，在选中报告旁显示完整 Run ID 和归档 SHA-256，并提供“查看对应任务”：用完整 Run ID 设置任务检索、清除旧状态筛选后进入任务中心。仍只使用现有已授权列表与任务接口，不新增服务端关系、权限或报告内容。实际执行者：Codex。

## 修改内容与对应位置

- `frontend/src/main.tsx::openSelectedReportTask`：仅在可见报告已选中时，设置同 Run 任务 ID、完整检索词和全部状态，再切换任务中心；报告列表展示短 ID，预览旁展示完整身份与入口。
- `frontend/src/layout.css::.report-detail`、`.report-identity`：身份卡响应式布局，长摘要与 UUID 可换行，窄屏改单列。
- `docs/REPORT_TASK_LINK_BROWSER_QA_2026-10-26.md`、总索引及 A/B/C/D 四责任包：记录页面实点及未验证边界。
