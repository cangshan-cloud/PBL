# CHG-20261024-013 历史结果只读复算与旧导出口径发现

## 问题与决策

已有历史导出核对仅比较复现 JSON、审计 CSV 与报告之间的一致性，无法回答“这份私有封存行情在当前源码下能否重新得到相同结果”。决定新增只读离线复算工具：要求同一封存包、成功的固定参数历史任务和有效的结果摘要，重跑四因子及指标，逐项比较；对浮点舍入设小容差，字段结构和计数严格比较。它复用当前实现，不能称为独立公式审计。实际执行者：Codex。

## 修改内容与位置

- `tools/verify_historical_recomputation.py::recompute_result`、`_same_result`、`verify_recomputation`、`main`：绑定导出数据集清单 SHA 与固定任务配置，只读重算并提示不一致字段。
- `backend/tests/test_historical_recomputation.py`：合成正例、重新计算过自摘要的指标篡改反例、舍入容差和非法任务配置反例。
- `docs/HS300_BUNDLE.md::审计 CSV 导出`：增加操作命令、当前源码边界与旧导出发现。
- `docs/PRD_ACCEPTANCE_MATRIX_2026-10-14.md::§9.4`：补充当前源码复算能力及旧归档不能作为当前口径精确证据的放行条件。
- `docs/CHANGE_INDEX.md`、A/B/C/D 四责任包：登记发现和实际执行者。

## 验证与边界

定向 2 项、项目虚拟环境后端全量 274 项、黄金手算核对及变更台账 208 条索引/46 条近期 A/B/C/D 链接均通过。用本机私有封存包对 2026-10-14 浏览器留存复现 JSON 只读复算，工具按预期返回不一致：旧结果缺六项后来新增的覆盖/跳过诊断，`group_returns` 与当前逐日聚合口径不同；四因子逐日审计相同，组合有效观测均为 72,366。旧导出并未被改写或删除。远端 CI 结果待提交后核对。该工具验证当前代码/同一数据能否复现，不独立验证公式、上游数据可信度或授权；旧结果未自动升级，最终需当前源码的新任务正例。分工 Excel 保持原样。
