# CHG-20261019-014 适配预览与导入绑定同一原文件

## 问题与决策

适配预览与正式导入是两次独立上传。此前即使预览显示了字段映射和周末警告，也无法保证管理员最终提交的仍是同一文件。决定让预览返回原始上传字节的 SHA-256；若页面沿预览流程导入，则携带该摘要，服务端在转换或写盘前比对本次原始字节。不同则以 409 拒绝并提示重新预览。字段保持可选，保留未预览直接导入的既有流程；格式非法或未启用适配却传摘要则以 400 拒绝。

这是预览—导入一致性校验，不是对行情真实性、数据来源许可或原始文件签名的认证。它也不替代导入后的不可变标准化 CSV 校验和：适配可能改变字段、日期或证券代码，所以两种摘要可能不同。

## 修改位置

- `backend/app/main.py::preview_adapted_dataset`：响应增加 `source_sha256`，取本次原始上传字节。
- `backend/app/main.py::import_dataset`：增加可选 `expected_source_sha256` 表单字段，先验格式、适配开关和字节摘要，失败时不调用导入写盘。
- `frontend/src/main.tsx::previewAdapter`、`uploadDataset`：保存预览摘要，仅在适配导入且存在预览时发送；文件选择改变则清除预览，预览请求期间文件改变则丢弃过期响应；预览卡片显示原文件摘要。
- `backend/tests/test_api_journey.py`：隔离 HTTP 用例覆盖同一文件成功、改价文件 409 且无草稿、非法摘要 400。
- `docs/CN_DATA_ADAPTER.md`、`docs/CHANGE_INDEX.md`、A/B/C/D 四责任包：记录协议、证据及限制。实际执行者：Codex。

## 验证与边界

后端全量 220 项通过；前端 33 项通过且生产构建成功；`git diff --check` 通过。未做浏览器文件选择和上传实点，页面链路只有类型检查与构建证据。后端回归使用合成 CSV 和隔离 SQLite，不代表真实行情或许可验收。

不要求所有适配导入都先预览，避免破坏现有 API 客户端；因此直接调用导入且不传预期摘要的请求仍由原有 CSV 质量规则保护，不具有预览绑定保证。管理员需要该保证时应先预览并携带返回值。
