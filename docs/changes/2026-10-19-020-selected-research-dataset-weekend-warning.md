# CHG-20261019-020 研究工作台所选数据版本周末提醒

## 问题与决策

CHG-20261019-019 的主栈浏览器验收发现：合成样本发布后，数据集页能定位周末行，但研究工作台默认选中最新版本时没有同样提醒。研究者可能离开数据集页后直接运行。决定在研究配置的所选数据版本下显示只针对该版本的提醒；不自动禁用任务，也不删改数据，因为周末计数只是简单日期诊断，尚非交易所日历认证。实际执行者：Codex。

## 修改内容与位置

- `frontend/src/dataset-alerts.ts`：新增 `selectedWeekendDatasetAlert`，仅对当前选中且周末行数非零的版本返回提醒对象；旧质量报告缺字段时不产生假警告。
- `frontend/src/main.tsx` 研究工作台配置区：展示所选版本名称、标识、版本号、周末日期和行数，并明确人工核对与不自动禁用的边界。
- `frontend/tests/dataset-alerts.test.ts`：覆盖未选择、旧质量报告、正常版和需复核版；`docs/CN_DATA_ADAPTER.md` 更新产品口径。
- `docs/CHANGE_INDEX.md` 与 A/B/C/D 四责任包同步记录。无后端、数据库或研究公式修改。

## 验证与边界

- Mac 前端 `npm test`：38/38 通过；`npm run build`：TypeScript 与 Vite 生产构建通过；`git diff --check` 通过。
- 本轮尚未重建 OrbStack Web 容器，也未进行这项新提示的浏览器视觉实点。现有 `http://localhost:5173/` 仍可能显示旧镜像，不能把单元测试/构建表述为部署验收。
- 周末提示不是节假日、停牌、上市状态或交易所交易日的完整核验；既有版本的原始行和研究任务权限均未改变。
