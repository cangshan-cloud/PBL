# CHG-20261018-006：实验对比浏览器实际下载验收

## 背景与决策

上一轮完成数值格式与 HTTP 回归，但没有验证页面按钮能否真正下载文件。本轮不扩展产品范围，使用隔离本机 API、前端与临时 SQLite，从登录到两次演示研究、实验对比、CSV/HTML 点击形成端到端证据。浏览器安全策略禁止打开本地 `file://` 文件，故不绕过限制；HTML 仅核对落盘与内容，打印视觉排版仍未验收。

## 实际执行与结果

- Mac 上独立临时 SQLite 和数据目录；内置演示快照。研究员登录后运行 20 日动量、5 日反转两条成功任务，再在实验对比页选择两者。
- 页面报告共同有效 IC 日 99、共同多空分组日 99、共同证券×日期观测 1980、收益标签差异 0；因实际日期集合不同，明确显示口径警告。页面有效观测差值 `+300`，IC 差值 `-1.1328`。
- 点击“下载 CSV”和“下载 HTML 报告”均触发浏览器下载事件并在 `~/Downloads/` 生成文件，分别约 3.2 KB 与 6.5 KB。CSV 两行任务数据保留原始浮点数，5 日反转观测差值为 `300`，IC 差值为 `-1.1327820690852042`；HTML 包含 `+300`、`-1.1328`、共同样本与口径差异警告。
- `playwright-cli` 因 npm 离线缓存缺失而未运行；使用应用内浏览器完成真实页面操作。浏览器拒绝 `file://` 打开下载的 HTML，本轮未做视觉或打印分页验收。未重跑后端／前端测试套件，沿用上一轮 210／23 项通过的基线，不能冒充本轮结果。
- 文件保留在用户下载目录供人工查看；隔离临时服务与数据库已清理。未改产品代码、真实 A 股样本或日常开发数据。实际执行者：Codex；四人责任包为代执行记录，非成员本人签收。
