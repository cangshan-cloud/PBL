# CHG-20261018-003：隔离多账号浏览器与权限回归

## 背景与决策

前两轮新增前端请求会话隔离，但只用可控 Promise 覆盖了慢响应时序。课程验收还需要确认真实页面在账号切换时不会展示上一研究员的任务、报告或实验对比候选；同时不能只靠前端隐藏，后端必须拒绝直接越权读取。

决定用独立临时 SQLite、数据目录和本机端口完成 A/B 两个研究员的浏览器路径，并把报告列表及 HTML 预览的跨账号断言补进已有 HTTP 回归。只使用演示快照与临时测试账号，不触碰日常开发数据库。Playwright CLI 包装脚本因 npm 仓库 DNS 不可达未能启动；实际页面检查改用应用内浏览器控制，明确不声称完成了 Playwright CLI 测试。

## 修改位置

| 内容 | 位置 |
| --- | --- |
| 第二研究员看不到第一研究员的报告列表项，直接读报告 HTML 返回 403 | `backend/tests/test_api_journey.py` 的多账号权限旅程 |
| 决策、验证证据及四责任包 | 本文件、`docs/CHANGE_INDEX.md`、`docs/member-deliverables/` |

## 隔离验证结果

- 临时环境：`/private/tmp/factorlab-auth-qa-o3xvmR`，API 端口 18001，前端端口 15174；测试结束已停止服务、关闭测试标签并删除该专用临时目录（含临时账号与测试库，不可恢复）。
- 管理员在该环境创建临时研究员 B；研究员 A 使用演示快照运行一条 20 日动量任务，任务与自动报告均成功。研究员 A 的任务中心、报告中心可见对应条目。
- 退出 A、登录 B 后，B 的个人总览任务／报告数均为 0；任务中心、报告中心和实验对比候选均无 A 的条目。
- B 携本人令牌直接请求 A 的任务详情与报告 HTML，均返回 HTTP 403。
- 后端完整单元测试 209 项通过。前端代码本轮未改；上轮 20 项前端测试和生产构建结果不冒充本轮重跑。

## 局限

浏览器实测覆盖普通账号切换，不具备精确网络延迟注入；A 的慢响应晚于 B 登录的竞态仍由 `frontend/tests/auth-resource.test.ts` 的可控 Promise 测试提供证据。本轮没有做 Compose/Celery、Windows、真实行情或正式用户验收。实际执行者：Codex；四人责任包为代执行记录，不代表成员本人签收。
