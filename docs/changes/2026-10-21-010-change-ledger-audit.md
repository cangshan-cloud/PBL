# CHG-20261021-010 变更台账只读结构校验

## 问题与决策

项目约定每次改动记录决策、代码位置、验证与四人验收责任，但目前主要靠人工记忆。本轮选择增加标准库只读校验器，提交前可重复运行；不自动改写历史记录，不把结构 PASS 解释为内容真实或研究结论正确。首次运行发现 CHG-004/008 对应五处责任包记录已有事实但缺变更单链接，故只补交叉链接，不改原验收结果。实际执行者：Codex。

## 修改内容与位置

- `tools/check_change_ledger.py` 的 `audit`/`main`：检查索引六列、ID 唯一、日期、记录链接与文件、近期孤儿记录，以及近期 CHG 的决策/位置/验证章节、仓库相对位置和四责任包链接；默认严格起点 2026-10-21，可用 `--since` 调整。
- `backend/tests/test_change_ledger.py`：正例，以及责任包缺链、孤儿记录、重复 ID、缺决策章节反例；历史记录宽松兼容。
- `docs/member-deliverables/B_数据工程与质量验收.md`、`C_因子研究与指标验证.md`、`D_产品测试与展示验收.md`：补 CHG-004/008 的现有证据链接；A 包原已链接。
- `docs/CHANGE_INDEX.md`：使用说明和本条记录；四责任包追加本轮验收边界。

## 验证与边界

`.venv/bin/python tools/check_change_ledger.py` 返回 PASS：172 条已索引记录、10 条近期 CHG 均在 A/B/C/D 包链接；4 个定向正反例通过；后端全量 **253 passed**，仅有一条第三方弃用警告。校验器不调用容器、网络或数据库，也不读取私有原始行情；只能发现台账结构缺口，不能证明引用位置仍准确、验收由队员本人完成或研究结果有效。Windows 未验证。
