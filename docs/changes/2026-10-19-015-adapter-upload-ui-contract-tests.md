# CHG-20261019-015 适配导入页面摘要契约回归

## 问题与决策

上一轮预览—导入原文件 SHA-256 绑定已有后端接口回归，但页面何时发送 `expected_source_sha256` 仅经过类型检查和构建。决定提取表单组装逻辑并给出三类独立前端测试：有有效预览时绑定、未预览或切回标准导入时不发送、预览摘要异常时明确要求重新预览。这样避免页面改动把有预览的导入静默降级为无绑定，也避免旧摘要进入标准导入。

## 修改位置

- `frontend/src/adapter-upload.ts::prepareAdapterImportBody`：清除任何旧预期摘要，仅在勾选适配且存在有效预览时设置 64 位小写 SHA-256；无效预览抛出可展示的中文错误。
- `frontend/src/main.tsx::uploadDataset`：使用同一函数构造上传表单。
- `frontend/tests/adapter-upload.test.ts`、`frontend/package.json`：新增三项回归并纳入常规前端测试命令。
- `docs/CHANGE_INDEX.md`、A/B/C/D 四责任包：记录决策、位置、证据与界限。实际执行者：Codex。

## 验证与边界

前端 36 项测试通过，生产构建成功；后端代码本轮未改，沿用 CHG-20261019-014 的 220 项后端通过证据。本轮未做浏览器文件上传实点，纯函数测试不等同于端到端页面验收。摘要仍只证明同一原文件字节，不能认证行情真实性或许可。
