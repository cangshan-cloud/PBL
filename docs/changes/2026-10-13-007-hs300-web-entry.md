# CHG-20261013-007 历史包网页入口

- 日期：2026-10-13
- 状态：implementation / partial
- 决策依据：`CHG-20261013-004` 的平台注册和 `CHG-20261013-006` 的专用任务 API；保持旧单 CSV 工作台独立。

## 修改内容与位置

- `frontend/src/main.tsx` 的 `Dataset`/`Result` 类型、`registerHistoricalBundle`、`runResearch`：识别数据包类型，管理员按 ID 注册草稿，历史模式向专用任务 API 提交固定参数。
- 同文件研究工作台与数据集页 JSX：隔离两类数据版本；历史模式隐藏旧参数，任务结果展示四因子审计摘要。
- `frontend/src/styles.css`：注册表单和审计表的响应式样式。
- `backend/app/services/datasets.py::preview_dataset`：历史包预览返回清单摘要而非尝试解析 manifest 为 CSV。
- `backend/tests/test_historical_bundle_registration.py`：验证摘要预览内容。
- `docs/HS300_BUNDLE.md`：说明网页操作和预览限制。

## 决策过程

用户需要能在网页完成最小闭环。前端按 `quality_report.dataset_kind` 分流，避免把历史包送往旧研究入口；历史模式仅开放已确认的分组数，其他参数由后端冻结。注册表单只接受包 ID，与后端目录约束一致。历史包不是单 CSV，预览改为可核对的清单摘要，避免浏览器显示乱码或误导为行情样本。

## 验证与限制

- `frontend` 的 `npm run build` 成功；后端全套测试及新增摘要预览测试见提交前运行结果。
- 尚未进行浏览器人工视觉与可用性验收。数据集通用卡片仍共用字段质量展示，历史包应以清单摘要和完整性核验为准；不是逐字段行情质量报告。真实包仍只存在本机，不入 Git。
