# CHG-20261019-003 真实样本对比导出一致性复测

## 问题与决策

同源演示任务已覆盖 API JSON、CSV、HTML 的身份、IC 和风险提示，但私有 10 股 BaoStock 样本此前只核对了 CSV 核心行与 HTML 验证期交集数。决定扩展现有只读验证脚本，在不重新联网采集、不上传私有行情、不修改项目数据库的条件下复跑当前代码与导出格式。

## 修改位置

- `tools/verify_real_a_share_sample.py`：逐任务核对 CSV/HTML 的完整 Run ID、数据版本 ID、代码版本、原始 IC、共同日期 IC，以及导出风险提示；保留既有 SHA-256、维度、五因子和验证期严格交集断言。
- `docs/REAL_A_SHARE_SAMPLE.md`：记录本轮结果与使用限制。
- `docs/CHANGE_INDEX.md` 与 A/B/C/D 四责任包：登记决策、验收和实际执行者。

## 验证与边界

后端全量 `python -m unittest discover -s backend/tests` 共 213 项通过。

`python tools/verify_real_a_share_sample.py` 使用原私有快照 SHA-256 `958e7bdcd5f6269d4e9630f586b91814b40019c043d610b344bd7d5ac381b652`，1170 行、10 股、2024-01-02 至 2024-06-28。五因子有效观测／IC 日期分别为动量 960/96、反转 1110/111、波动率 960/96、换手率 970/97、市盈率 1160/116，与既有基线一致。动量与反转的共同有效 IC 日 96，预设 `2024-04-01` 验证期共同有效 IC 日 58；严格样本交集全区间 960、验证期 580 条，次日收益标签差异 0。验证期最少有效 IC 日 58，等级 `limited`。新增身份、IC、风险提示导出核对通过。

这证明当前代码在本机固定私有样本上的软件输出一致，不代表因子显著、可交易、未来有效，也不消除固定 10 股样本的选择偏差。原 CSV 未纳入公开仓库或验收文档；没有重新联网获取或公开再分发。实际执行者：Codex。
