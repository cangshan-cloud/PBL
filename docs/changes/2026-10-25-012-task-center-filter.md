# CHG-20261025-012 任务中心检索与状态筛选

## 问题与决策

研究任务累计后，任务中心只有按时间排列的列表，不便按 Run ID 或研究名称定位。决定增加纯前端检索与状态筛选，保留原排序；详情只绑定可见任务，零匹配时不展示旧任务详情，避免误读。它不改变服务端任务查询或权限。实际执行者：Codex。

## 修改内容与对应位置

- `frontend/src/task-filter.ts::filterTasks`：按 Run ID/研究名称忽略大小写检索，并叠加状态过滤，保持原顺序。
- `frontend/src/main.tsx` 任务中心：检索框、状态选择、命中数、无匹配提示；当前详情跟随可见结果。
- `frontend/src/layout.css`：响应式筛选控件布局。
- `frontend/tests/task-filter.test.ts`、`frontend/package.json`：检索、状态组合与零命中回归。
- `docs/TASK_FILTER_BROWSER_QA_2026-10-25.md`、索引及 A/B/C/D 四责任包：记录真实页面验收和边界。

## 验证结果与边界

前端 59 项测试及生产构建通过。隔离浏览器 6 项任务按 ID 检索成 1 项，状态组合成 0 项时详情清空，控制台错误/警告 0；未运行新任务。后端全量回归、黄金核对、台账和链接检查见本轮提交。本功能不替代服务端授权，也未做大规模性能验收；用户修改的 Excel 未处理。
