# CHG-20261023-006 调整价报告披露全版本乘数缺失范围

## 问题与决策

逐证券守卫允许完整证券子集成功研究，但其归档报告此前只体现选中样本的成功结果，读者可能误以为整份数据版本都可用于调整价。决定在**新生成**的调整价报告和披露版交付副本中，依据版本质量报告的 `missing_counts.adj_factor` 提示全版本仍有空值，并明确成功范围只限所选样本。原始导入价无需该警告；不修改旧归档。实际执行者：Codex。

## 修改内容与位置

- `backend/app/services/reports.py::_dataset_risk_disclosures`：增加与研究价格口径相关的全版本缺乘数披露；`build_report_html` 和 `report_delivery_copy` 传入任务参数。
- `backend/tests/test_reports.py`：覆盖调整价归档报告、披露版副本以及原始导入价不误报；兼容历史模拟对象无 `parameters` 的测试。
- `docs/PRICE_BASIS.md`、开发计划、PRD 验收矩阵、总索引及 A/B/C/D 四责任包：同步口径与边界。

## 验证与边界

报告模块 15 项、后端全量 **262 项**通过；`git diff --check` 与变更台账检查通过。本轮未重新构建容器或在浏览器生成新报告，因此不把既有 Run `94cf90bd` 的归档说成已更新。其归档字节不可变；新逻辑只适用于后续新报告，动态交付副本会按当前数据质量报告补充警告。

警告是质量报告的全版本空值计数，不认证复权乘数来源、停牌或真实市场有效性；若旧版本没有缺失计数字段，不臆测。
