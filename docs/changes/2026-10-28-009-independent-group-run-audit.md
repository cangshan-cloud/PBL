# CHG-20261028-009 逐股观测到分组、多空和成本的独立验算

## 问题与决策

前轮已独立验算实际 Run 的全期 IC，但分组和多空表现仍主要依赖应用研究算法复算及导出同源检查。决定增加标准库只读工具，从私有逐股观测重新排序分组、累计净值、计算换仓和固定成本，再逐日比较 V2 保存结果。历史 Run 全部日期足够分组；工具遇到不足样本或因子恒定日会显式拒绝，避免将这类日期误报为已验。实际执行者：Codex。

## 修改内容与对应位置

## 验证与未决事项

新 Celery Run 的 72,366 条观测、242 日、5 组、1,210 个组净值点和 242 条多空序列逐值通过，最大差 0。构造单测 3 项通过；后端全量、黄金核对、台账与文档链接检查随提交执行。只验证观测产物到报告指标的计算，未独立核验全期原始行情或市场交易可行性。用户修改的分工 Excel 不处理。
