# CHG-20261026-015 逐日表绑定隔离 API 交付链路

## 问题与决策

CHG-20261026-014 已验证折叠表的生成函数与合成报告排版，但尚未覆盖通过实际 API 完成一次任务后，归档、预览及交付副本是否都承载同 Run 的表。决定扩展既有合成 CSV 隔离 HTTP 闭环测试：不另起服务、不接触私有数据，用刚完成任务的复现 JSON 作逐行比较依据。保持产品代码与结果计算不变。实际执行者：Codex。

## 修改内容与对应位置

- `backend/tests/test_api_journey.py::test_upload_publish_research_report_and_role_boundaries`：沿用导入→发布→inline 研究成功路径，从同 Run 复现包取得 IC、Rank IC、多空和各组已存序列；按日期并集逐行构造期望四位小数/空值，与归档 HTML 的折叠表全部行核对，并检查行数、组列数。
- 同一测试确认报告预览字节等于原归档下载、交付副本含同一折叠表且声明的原归档 SHA 与下载字节一致；既有另一研究员访问拒绝断言继续保留。
- `docs/SINGLE_FACTOR_ANALYSIS.md`、本索引及 A/B/C/D 四责任包记录证据边界；无生产代码改动。

## 验证与未决事项

定向 HTTP 用例通过；后端全量 293 项、前端 80 项、前端生产构建和黄金样例通过；台账/链接检查见本轮提交。测试使用仓库合成 CSV、内存 SQLite 与临时产物目录，不启动 Docker/Celery，也不证明真实行情、独立再计算或用户本人实测。由于表格只保留四位小数，此处验证的是归档展示值与同 Run 保存结果的一致性，不是浮点全精度或投资有效性。既有归档不改写。
