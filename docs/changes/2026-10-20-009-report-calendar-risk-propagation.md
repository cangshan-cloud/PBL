# CHG-20261020-009 报告交付链路传递公告休市诊断

## 问题与决策

数据集与适配预览已经提示公告休市工作日行情和离线规则未覆盖年份，但报告中心、后续新生成报告及披露版下载的风险文字尚未完整传递这两类诊断。研究人员可能在报告交付时遗漏源数据限制。决定共用一处数据版本风险提取逻辑：仅从该报告绑定的数据版本质量报告读取事实，不重新计算指标，也不把“未命中”说成真实交易日合规。旧归档 HTML 继续按原字节和校验和保存；报告中心使用外层提示，下载使用派生披露副本。实际执行者：Codex。

## 修改内容与位置

- `backend/app/services/reports.py`：`_dataset_risk_disclosures` 集中提取精确识别的内置合成演示数据、周末行、公告休市命中行/日期/规则版本及未覆盖年份；`build_report_html` 将风险写入**新生成**的报告；`report_delivery_copy` 将同样风险转义后写入**派生**交付副本。
- `frontend/src/main.tsx` 报告中心：按报告绑定的 `dataset_version_id` 与 SHA-256 选取数据版本后，在预览外围展示公告休市命中日期和未覆盖年份，并明确旧归档不改写。
- `backend/tests/test_reports.py`：覆盖新报告、派生副本、合成演示身份区分与恶意日期 HTML 转义。既有报告权限和归档校验测试继续执行。
- 本记录、`docs/CHANGE_INDEX.md`、`docs/ORBSTACK_DEPLOYMENT.md` 与 A/B/C/D 四份独立验收材料同步更新。
