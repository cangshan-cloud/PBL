# CHG-20261026-020 新报告曲线同步提示内部全线空缺

## 问题与决策

网页曲线已显式列出已知的内部全线空缺日，但新 HTML 报告的逐日核对表默认折叠，读者只看图时不易发现断点。决定让新生成报告的 IC/Rank IC、多空和各组净值图采用与网页相同的限定：仅列两个有效点之间、该图所有线均无有限值的已知日期。只读已有结果和诊断，不改变研究计算、CSV 或旧归档。实际执行者：Codex。

同时补验上一轮网页提示：隔离旧 Run 无误报；浏览器会话内临时追加一个周末构造诊断日后，三图均出现提示，展开日期和免责声明正确。该拦截未写数据库，不能当真实市场证据。详情见[浏览器记录](../CHART_GAP_BROWSER_QA_2026-10-26.md)。

## 修改内容与对应位置

- `backend/app/services/reports.py::_interior_all_missing_dates`：在报告对齐日期上计算内部全线空缺日，排除边缘及只有部分线缺值的日期。
- `backend/app/services/reports.py::_svg_chart`：仅在有内部全线空缺时输出可展开数量、转义后的日期与限制说明；报告 CSS 为长日期列表限高折行。
- `backend/tests/test_reports.py`：验证已知诊断独有日期在三张报告图分别提示，边缘/部分线缺值不误报，旧有断线行为保持。
- `docs/SINGLE_FACTOR_ANALYSIS.md`、[浏览器记录](../CHART_GAP_BROWSER_QA_2026-10-26.md)、本索引及 A/B/C/D 四责任包：登记口径、执行位置和验收边界。

## 验证与未决事项

报告专项 20 项通过；全量后端、前端、构建和黄金样例以及台账检查见本轮提交。新报告提示由 HTML 回归覆盖，**本轮没有新报告浏览器或打印视觉实点**；旧归档不回写。浏览器正向验收只注入构造日期，非真实市场缺口。队长本人产品实测仍待完成。
