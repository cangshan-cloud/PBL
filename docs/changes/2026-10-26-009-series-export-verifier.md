# CHG-20261026-009 每日序列 CSV 与复现包离线逐行核对

## 问题与决策

此前每日 IC 与多空 CSV 已经浏览器落盘，但只验证了行数、身份和局部字段关系，尚未独立逐行比对保存的复现结果。决定增加标准库只读工具，核对一个或两个 CSV 与同 Run 复现 JSON 的字段值和顺序；不改变业务计算，也不把自带 SHA 当外部签名。实际执行者：Codex。

## 修改内容与对应位置

- `tools/verify_series_exports.py`：先复用复现 JSON 的版本、重复键和结果 SHA 校验，再核对固定 CSV 表头、行数、日期顺序、Run 身份、空值和各字段数值；支持 IC 或多空单独校验。
- `backend/tests/test_series_exports.py`：正例及错 Run、缺行、换序、篡改数值/成本/列名、非有限数、校验和不符、重复键、空序列反例。
- `docs/SERIES_EXPORT_VERIFICATION.md`、`docs/SERIES_EXPORT_QA_2026-10-26.md`：使用命令、真实旧 Run 三文件核对结果及身份未被 SHA 覆盖的边界。
- 总索引和 A/B/C/D 四责任包：保留本次决策和各包对应的代执行证据。

## 验证与限制

隔离 API 的旧 Run 复现 JSON 与两份浏览器下载 CSV 均逐行一致，各 242 行；后端全量回归、前端测试/构建、黄金样例、台账与链接检查见本轮提交。工具不重算因子、不证明市场数据真实或授权，也不能抵御协调篡改复现包身份与 CSV 身份。隔离卷保留、容器关闭，用户修改的 Excel 未触碰。
