# CHG-20261013-006 历史沪深300专用平台任务

- 日期：2026-10-13
- 状态：implementation + evidence / partial
- 决策依据：`DEC-20261012-004` 的旧演示隔离、`DEC-20261012-009` 的参数冻结，以及 `CHG-20261013-005` 的计算核心。

## 修改内容与位置

- `backend/app/schemas.py::HistoricalResearchRequest`、`backend/app/main.py::create_historical_task`：专用 API，只接收已发布历史包数据版本 ID 与分组数。
- `backend/app/services/runs.py::create_historical_run`：冻结四因子、窗口、等权、预处理和成本参数；`execute_research_run` 的历史分支重新验证整包并保存指标和 HTML 报告。旧任务分支不变。
- `backend/app/domain/historical_research.py::calculate_historical_observations`：对有因子信号但无有效 t+1 标签的观察保存逐行日期、证券、值、下一市场日和原因。
- `backend/app/services/reports.py::build_report_html`：历史报告增加因子覆盖和排除审计表，并声明不能视为可成交回测。
- `backend/tests/test_historical_task.py`、`backend/tests/test_historical_research.py`：专用任务成功/拒绝路径、报告、逐行无标签审计。
- `docs/HS300_BUNDLE.md`：接口、试跑证据和限制。

## 决策过程

不把历史包塞进旧单 CSV 任务。采用独立任务入口、统一 Run/Artifact 基础设施，避免新增数据表与重复调度器；Worker 执行时再次检查数据状态和完整包。首期按已确认范围冻结四个因子，仅开放分组数，减少参数空间。共用报告模板但加入历史审计和限制说明。

## 验证与未决

- 私有真实包通过平台服务端到端试跑：Run 成功，生成 metrics 和 report_html，等权组合覆盖 72,366 个有效观察。
- 合成包任务单测及无标签反例通过；后端全套测试见提交前运行结果。
- 尚无网页专用创建界面；仍需更深入核验报告中的指标解释、历史数据业务语义和报告视觉版式。固定成本后净值只是研究敏感性展示，不是可成交收益。私有数据包不进入 Git。
