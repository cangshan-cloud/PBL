# CHG-20261026-011 任务中心回看旧 Run 逐日曲线

## 问题与决策

旧成功任务虽然有摘要指标、逐日诊断及三类 CSV，但研究人员无法直接在任务详情回看曲线。决定复用工作台已有图表，在任务详情增加默认收起的回看区；切换 Run 时按 ID 重置面板，避免旧图误认为新任务结果。仅读取保存的结果，不重新执行研究。实际执行者：Codex。

## 修改内容与对应位置

- `frontend/src/main.tsx::SavedSeriesCharts`：抽出当前研究和旧任务共用的 IC、多空、各组净值图；任务详情关闭图内重复下载按钮与分布图，上方原三类 CSV 下载保留。
- `frontend/src/main.tsx` 任务中心：按 Run ID 作为折叠区 `key`，默认收起；展开时呈现当前任务的图表，区域无障碍名称含完整 Run ID。
- `frontend/src/layout.css`：任务详情内单列、浅底图表布局，避免嵌套双列挤压。
- `docs/SINGLE_FACTOR_ANALYSIS.md`、`docs/TASK_SERIES_CHART_BROWSER_QA_2026-10-26.md`、总索引及 A/B/C/D 四责任包：记录回看口径与两 Run 隔离实点。

## 验证结果与边界

前端 78 项测试及构建通过；隔离浏览器两条旧成功 Run 的展开、切换收起及完整身份绑定实点通过，控制台无错误/警告。后端全量回归、黄金样例、台账与链接检查见本轮提交。研究工作台新任务入口未重做浏览器验收；图表是描述性展示，不认证数据真实性、策略有效性或可成交收益。私有证据和用户修改的 Excel 不入库。
