# CHG-20261023-009 普通 CSV 报告来源认证边界披露

## 问题与决策

普通 CSV 数据版本的质量报告即便未命中周末或已知公告休市异常，也只完成平台内格式与有限日期检查，不能证明数据真实性、使用授权或完整交易日历。此前新归档报告可能没有对应来源风险说明。决定对质量报告带 CSV 字段清单、且非封存历史包和非已识别内置演示数据的版本，在**新归档报告**和动态交付副本中持续披露认证边界；不改写旧归档。实际执行者：Codex。

## 修改内容与位置

- `backend/app/services/reports.py::_dataset_risk_disclosures`：普通 CSV 增加通用来源/授权/日历未认证说明；已识别内置演示数据保留专属合成数据说明，封存历史包不套用普通 CSV 文案。
- `backend/tests/test_reports.py`：覆盖普通 CSV 无已知日期异常仍需说明、交付副本同步说明、封存历史包不误标。
- `backend/tests/test_api_journey.py`：隔离 CSV 导入发布至调整价/原始导入价研究报告的 HTTP 链路均保留通用说明，调整价特有缺乘数提示仍仅对应调整价。
- `docs/PRICE_BASIS.md`、开发计划、PRD 验收矩阵、总索引及 A/B/C/D 四责任包：同步本轮决策和边界。

## 验证与边界

报告模块 16 项、后端全量 **263 项**通过；变更台账与 `git diff --check` 通过。本轮未更新容器或浏览器，旧归档字节不变；旧归档的动态交付副本会按当前质量报告追加该说明。

通用提示不是“数据一定有问题”的判断，也不替代真实来源授权文件、交易所日历核对和财务时点审计。对封存历史包已有独立验证口径，本轮未改变其认证范围。
