# PRD 规模性能验收（Mac）

## 验收口径

PRD 的目标是“300 只股票、3 年日频、单因子完整检验不超过 60 秒”。运行：

```bash
# 先激活项目 Python 虚拟环境
python tools/benchmark_prd_scale.py
```

脚本生成 300 只虚拟股票 × 756 个周一至周五日期，共 226,800 行 CSV。日期仅作为 3 × 252 交易日的规模近似，不模拟中国节假日。数据由固定公式生成到系统临时目录，任务结束后清理；仓库不保存大文件。

计时分为两部分：

1. 研究核心：SHA-256 校验与读取、20 日动量计算、五分组统计检验、结果 JSON 序列化。
2. 完整 Run：将同一 CSV 导入并发布后，从执行任务开始，到 SQLite 保存指标、生成独立 HTML 报告并完成任务为止。导入与发布耗时单独报告，不计入 60 秒任务阈值。

脚本检查行数、有效观测数、任务成功状态和报告产物；超出 60 秒时返回非零退出码。默认启用 MAD 去极值、截面 Z-score 标准化和 10 bps 单边成本，与研究工作台默认口径一致。

## 2026-10-11 Mac 实测

环境：macOS 14.6.1，Apple Silicon（arm64），Python 3.13.3，本地 SQLite 内联任务模式。

| 阶段 | 用时 |
| --- | ---: |
| 文件校验与读取 | 0.505 秒 |
| 因子计算 | 0.225 秒 |
| 统计检验 | 0.605 秒 |
| JSON 序列化 | 0.005 秒 |
| 研究核心合计 | 1.340 秒 |
| 数据导入与发布（阈值外） | 0.569 秒 |
| 完整 Run（含持久化与 HTML 报告） | **1.614 秒** |

有效观测数为 `300 × (756 − 20 − 1) = 220,500`。完整 Run 在该 Mac 环境下低于 60 秒目标。上述数字是单次本机测量，不代表跨设备保证。
