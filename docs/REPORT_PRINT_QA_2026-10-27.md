# 新报告打印版合成样例验收（2026-10-27）

本轮由 Codex 在 Mac 上代执行。以当前 `build_report_html` 和内存库生成含构造断点的合成报告，仅通过 `127.0.0.1:18229` 临时提供页面，用浏览器生成 PDF，再将六页逐页渲染为图片目视检查。浏览器和临时服务器已关闭。生成的 HTML、PDF 与图片只留在被忽略的本机 QA 路径和 `/private/tmp`，不作为正式研究报告或可移植发布证据。构造日期 `2024-01-06` 是周末样例，不代表真实交易日。

首次打印检查发现：三张图、日期、长代码版本号和正文没有裁切；但网页默认折叠的逐日序列核对表在 PDF 中只留下表格标题，容易让读者误认为明细已随报告打印。考虑真实任务可能有数百个日期，决定不强制展开宽表，而在打印版隐藏交互折叠控件，明确写出已知日期数及“打印版不包含逐日明细；请在同 Run HTML 报告展开查看，或核对逐日 CSV 与复现包”。网页版表格及其数据保持不变。

重新生成的六页 PDF 再次逐页检查：曲线、风险说明、结论和长版本号无可见裁切或遮挡；第五页在图表后清晰显示“逐日序列核对表含 3 个已知日期”及明细获取路径，不再出现仅有折叠标题的歧义。合成报告内容较少，分页留白不代表真实任务的页数。临时静态服务器唯一控制台错误为缺少 `/favicon.ico` 的 404。

这证明本轮合成报告的默认打印行为，不等于真实任务报告或用户本人验收；旧报告归档不回写。对应决策见 [CHG-20261027-002](changes/2026-10-27-002-report-print-detail-disclosure.md)。
