# 研究任务的代码指纹

每个新实验在创建时记录 `src-sha256:<64位十六进制值>`，由 `backend/app/` 下按相对路径排序的所有 Python 源文件，以及 `backend/pyproject.toml` 的内容生成。计算前统一 CRLF/LF 换行，避免 Mac 与 Windows 的换行差异造成假版本差异。该值写入实验、任务接口、报告和实验对比信息；历史实验不随新部署改写。

Worker 开始执行任务时重新计算本机指纹。若与实验创建时记录的不一致，任务转为 `failed` 并写入错误摘要与日志，不会用不同版本的计算代码静默生成结果。更新 API/Worker 镜像时应同时构建与启动；若有旧版本排队任务失败，可在新版本中使用“重试”创建新实验，旧记录保留。

这里记录的是**源码内容指纹**，不是 Git 提交号。这样即使本地有尚未提交的代码变化，实验也不会误标为上一条提交。它覆盖后端源码与直接依赖声明，不覆盖操作系统、外部数据库状态、前端代码或所有间接依赖的实际版本；数据校验和、因子版本、参数与任务日志仍需一并保存，才能构成完整复现证据。旧任务中的 `development` 是历史占位值，不会追溯补写。
