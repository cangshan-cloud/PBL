# 严格同样本 IC 独立黄金验算

本材料给出一个可手算的小样本，用来检查实验对比中的共同“信号日期 × 证券”交集、IC、Rank IC、ICIR 和 IC 为正比例。它不是 A 股真实样本，也不证明投资有效性。对应自动测试：`backend/tests/test_matched_comparison_golden.py`。

## 固定输入

共同证券为 A、B、C；三个信号日为 2025-01-02、01-03、01-06。每日期次日收益依证券顺序均为 `(0, 0.01, 0.02)`。不做去极值或标准化，分组数为 2。

| 信号日 | Run A 的因子 A/B/C | Run B 的因子 A/B/C | 次日收益 A/B/C |
| --- | --- | --- | --- |
| 01-02 | 0 / 1 / 2 | 2 / 1 / 0 | 0 / 0.01 / 0.02 |
| 01-03 | 2 / 1 / 0 | 0 / 1 / 2 | 0 / 0.01 / 0.02 |
| 01-06 | 1 / 0 / 2 | 1 / 2 / 0 | 0 / 0.01 / 0.02 |

Run A 在 01-02 另有证券 X，因子 99、次日收益 0.99；Run B 不含 X。因此交集应恰为 **3 日 × 3 股 = 9 条**，X 不应影响任何严格同样本 IC。
原观测分别为 Run A 10 条、Run B 9 条，因此共同样本保留率应为 **90%** 与 **100%**；最小保留率为 90%。

## 独立期望值

每天用 Pearson 相关计算截面 IC；因子与收益均无并列，秩相关 Rank IC 与 IC 相同。Run A 三日 IC 为 `(1, -1, 0.5)`；Run B 为 `(-1, 1, -0.5)`。第三日例如 Run A 因子中心化为 `(0, -1, 1)`、收益中心化为 `(-0.01, 0, 0.01)`，相关系数为 `0.01 / (√2 × √0.0002) = 0.5`。

| 指标 | Run A | Run B |
| --- | ---: | ---: |
| IC 均值 | 1/6 | -1/6 |
| Rank IC 均值 | 1/6 | -1/6 |
| ICIR（每日 IC 总体标准差作分母） | 1/√26 | -1/√26 |
| IC 为正比例 | 2/3 | 1/3 |
| 有效 IC 日 | 3 | 3 |

Run A 的 IC 总体方差为 `13/18`，所以 `(1/6) / √(13/18) = 1/√26`。两个 Run 的次日收益标签在共同键上完全一致，差异数为 0。最少有效 IC 日只有 3，证据提示应为 `insufficient`：**公式可核对，不代表稳定性**。

这组期望值写在测试断言里，不调用平台函数生成“预期结果”；平台函数只产生被检验的实际值。测试通过仍不替代真实行情来源、披露时点或前瞻样本验证。
