# 沪深 300 历史因子独立抽样验算材料

本页只对两只股票、两个 2024 成员日作原始 CSV 的公式抽样复核；不是对 72,600 个成员日或研究指标的全面独立重算。封存包未随 Git 分发，复核者必须先获得同一私有包并运行 `python3 tools/verify_hs300_bundle.py <包目录>`。抽样脚本仅依赖 Python 标准库，**不导入平台研究实现**：

```bash
python3 tools/independent_hs300_spotcheck.py data/real/bundles/hs300_2024_0375298bd2c8ac52 2024-01-02 sh.600000
python3 tools/independent_hs300_spotcheck.py data/real/bundles/hs300_2024_0375298bd2c8ac52 2024-03-19 sh.600584
```

脚本直接读取 `prices_source/trade_calendar.csv`、对应日期的 `members_source/daily_rosters/*.csv` 和对应证券的 `prices_source/symbols/*.csv`。所有价格均为包内 BaoStock `adjustflag=1` 的源 `close`，不再二次复权；窗口按市场交易日而非自然日计算。设 `C_t` 为 t 日收盘价，`r_i=C_i/C_(i-1)-1`，则动量为 `C_t/C_(t-20)-1`；反转为 `-(C_t/C_(t-5)-1)`；波动率为连续 20 个日收益的**总体标准差** `sqrt(Σ(r_i-r̄)^2/20)`；换手率因子为 t-19 至 t 的 `turn` 平均值。只有次一市场日可用时，收益标签为 `C_(t+1)/C_t-1`。

| 抽样 | 原始关键值与状态 | 独立计算结果 | 平台同点输出 |
| --- | --- | --- | --- |
| 2024-01-02，`sh.600000` | t-20=2023-12-04，`C_(t-20)=81.37804266`；`C_(t-5)=78.62959188`；`C_t=78.86858760`；下一市场日 2024-01-03，`C_(t+1)=79.34657904`，正常交易 | 动量 `-0.030837004405286472`；反转 `-0.003039513677811412`；波动率 `0.007438751062379865`；平均换手 `0.08841`；次日收益 `0.0060606060606061` | 五项差异均小于 `1e-12` |
| 2024-03-19，`sh.600584` | t-20=2024-02-20，`C_(t-20)=88.78730020`；`C_(t-5)=105.89716120`；`C_t=103.94700500`；下一市场日 2024-03-20 为停牌 | 动量 `0.17074181516784082`；反转 `0.018415566365531544`；波动率 `0.036573850387257786`；平均换手 `2.3693549999999997`；**不生成次日收益**，原因为 `label_suspended` | 四项因子值差异均小于 `1e-12`，缺失标签原因一致 |

第一行可直接代入 `78.86858760 / 81.37804266 - 1`、`-(78.86858760 / 78.62959188 - 1)` 和 `79.34657904 / 78.86858760 - 1`；波动率与平均换手需读取连续 21/20 个源 CSV 行，脚本输出完整计算结果。第二行虽有次日源 `close`，但 `tradestatus=0`，因此不能把相同价格形成的“0% 收益”当作有效标签，也不能跳至复牌日。

2026-10-14 本机执行上述两个命令，并与平台 `calculate_historical_observations` 输出逐项对比：8 个因子值与正常/缺失标签一致，绝对误差上限 `1e-12`。这验证局部公式和 t/t+1 处理，但**不验证**历史成分生效日期、ST 来源准确性、整期 IC/收益聚合、成交可行性或投资效果。成员 C 可据此亲自复算、记录机器环境与差异并签名；此页和脚本本身不等于其个人验收已完成。
