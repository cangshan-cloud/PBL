# 交易成本分析

研究表单提供单边成本 `transaction_cost_bps`，范围 0—100，新增任务默认 10 个基点（0.1%）。这是供课程实验调整的假设值，不是实际券商收费标准。

计算保留毛收益，另输出成本后多空收益、日净收益与净值曲线。每条多空腿以 1 单位名义本金计量，组合为多头 1、空头 1；收益分母采用 1 单位名义本金，不是资金账户回报。

对每个交易日，将最高组和最低组分别构造成等权目标组合。每条腿的交易额为新旧目标权重差的绝对值之和，首次建仓为 1，全部更换为 2（卖出原成员并买入新成员）。因此：

```text
成本 = (多头交易额 + 空头交易额) × 单边成本基点 / 10000
净日收益 = 毛多空日收益 - 成本
净值(t) = 净值(t-1) × (1 + 净日收益)
```

两只股票、两组的人工验算例：每日毛多空收益均为 1%，单边成本为 10 bps。首次两腿建仓共扣 0.2%，次日两腿全部互换共扣 0.4%，两日净值为 `1.008 × 1.006 = 1.014048`。

模型计算目标权重之间的交易额，没有模拟持仓价格漂移造成的再平衡、期末平仓、融券可得性、借券费用、资金利息、税费买卖差异、涨跌停或非线性冲击。A股多空组合在此属于研究指标，不能视为可直接执行的交易方案。

头部组换手率为目标权重交易额的一半，统计时排除首次建仓；多空交易额指标包含首次建仓，不能混为同一口径。股票池和组规模改变时，计算也会考虑存续股票权重变化。

新任务固定保存成本参数；历史指标和历史报告不改写。旧任务未保存成本后收益时展示为空，对比服务给出缺失提示。不同成本假设的任务对比时同样给出提示。
