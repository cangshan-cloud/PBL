# 沪深 300 历史股票池数据可行性探针

状态：2024 全年成分查询、完整性校验及一次官方调整名单核验通过；价格、停牌/ST 状态及完整数据包未完成，因此尚未通过 10 月 31 日完整数据闸门。这里的结果不构成因子研究结论，也不证明所有成分维护事件的生效时点。

## 使用方法

在已安装 `baostock==0.9.4` 的 Python 环境运行：

```bash
python tools/probe_hs300_history.py --start 2024-06-28 --end 2024-07-01 \
  --output-dir data/real/hs300_probe_20241012
```

输出目录必须为空。程序保存 `trade_calendar.csv`、`hs300_members_queries.csv` 和 `manifest.json`。前两者属于私域原始数据，所在 `data/real/` 已被 Git 忽略；公开仓库不分发数据。清单记录来源、查询时间、包版本、日期和逐文件 SHA-256。采集脚本不会修改已有目录，也不会把查询日默认为指数成分生效日。

## 2026-10-12 真实探针结果

本机 `.venv` 中 BaoStock 0.9.4 查询 2024-06-28 至 2024-07-01：日历连续四个自然日、其中两个交易日；每个交易日返回 300 个不重复证券，共 600 行成分查询结果。2024-06-28 返回的 `updateDate` 均为 2024-06-24；2024-07-01 返回的均为 2024-07-01，两日成分集合相同。文件 SHA-256：

- `trade_calendar.csv`: `49fa351383c7c4535d19956e7c068cb8d09e34340727cc43e185548c91dbf71b`
- `hs300_members_queries.csv`: `9c1fe42d022d0f734f75dafdbed66e81a0541d309b0c3713f1c8a54d4fba1dc0`

首次普通沙箱调用因 BaoStock 连接超时失败；允许网络访问后重试成功。重复采集可能受到上游修订影响，应保留各自清单，不用新结果静默覆盖旧结果。

随后分别查询 2024-01-02 与 2024-12-31，均返回 300 个唯一成员。两端点集合相比，年初名单中的 28 只不在年末名单，年末名单中另有 28 只不在年初名单。这证明该接口并非只返回同一份当前成分名单，但**不能**据此确定这些变化在年内哪一天生效；逐日查询和独立边界核验仍是必需的。

## 2026-10-13 全年成分采集与边界核验

运行 `tools/fetch_hs300_members.py` 查询 2024-01-01 至 2024-12-31，数据保存在本机 Git 忽略目录 `data/real/hs300_members_2024/`。脚本逐日保存 300 个成员及原始 `updateDate`，中断后可验证既有检查点并续采；完成后生成汇总 CSV 和含逐文件 SHA-256 的清单。复验命令：

```bash
python tools/verify_hs300_members.py data/real/hs300_members_2024
python tools/verify_hs300_official_2024.py data/real/hs300_members_2024
```

完整性复验结果为 242 个交易日、72,600 条成分记录。逐日查询名单只在 2024-06-17（12 出/12 入）及 2024-12-16（16 出/16 入）发生变化。汇总文件 SHA-256 为 `dc1d04e918896ad77b616b7607f10c1d7baf250b0f0946a84252ff84041b2679`；交易日历 SHA-256 为 `9f5824d59519407d5827ef7fd8fa17710ea7535ece51e89be36d9631340b9191`。各日原始文件的哈希保存在本地清单中，仓库不分发原始数据。

独立核验选取 12 月定期调整：[中证指数官方 2024 年 11 月调整名单附件](https://oss-ch.csindex.com.cn/notice/20241129172348-%E9%99%84%E4%BB%B6%EF%BC%9A%E9%83%A8%E5%88%86%E6%8C%87%E6%95%B0%E6%A0%B7%E6%9C%AC%E8%B0%83%E6%95%B4%E5%90%8D%E5%8D%95.pdf)列出的沪深 300 调出/调入各 16 只，与 12 月 13 日和 16 日的 BaoStock 名单差集**逐只一致**。按[中证指数沪深 300 编制方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000300_Index_Methodology_cn.pdf)的定期调样规则，12 月第二个星期五后的下一交易日实施；2024 年对应 12 月 16 日。这是基于官方规则与查询结果的交叉核验，不是官方对 BaoStock 每日数据逐行背书。6 月 17 日的 12 出/12 入也与[2024 年 6 月调整报道所述数量和生效安排](https://jrj.sh.gov.cn/SCDT197/20240603/4d3202d0556a4cb2a0497a1f77c32897.html)一致，但尚未逐只比对官方 6 月名单。

## 仍须完成的闸门

1. 采集至少 20 个交易日预热价格、2024 正式期价格与交易/ST 状态，并验证停牌缺行的实际表现；当前成分快照不包含这些数据。
2. 制作不可变的价格/成分/日历/状态数据包，验证每个组成文件的哈希、日期覆盖和状态完整性，再接入新研究模式。在此之前只能称“历史成分查询证据”，不能宣称完整历史选股回测可信。
3. 进一步核验 6 月官方完整名单及可能的临时调整、源数据修订；本次一次官方定期调整交叉核验不等于完全消除未来成分偏差。
