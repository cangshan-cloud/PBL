# 结构化研究结论模板

## 1. 目标

系统根据成功任务已经保存的指标生成一份“结论—证据—限制—下一步”草稿，帮助不熟悉因子研究的团队成员按照统一结构解释结果。该功能使用固定规则，不调用大语言模型，不补造指标，也不替代研究人员判断。

任务中心会动态展示草稿；此后新生成的单因子和多因子 HTML 报告也会包含同一份草稿。旧报告文件保持不可变，不会被后台覆盖，但仍可通过结论接口查看最新规则生成的草稿。

## 2. 判定规则

当前规则版本为 `1.0.1`：

| 维度 | 规则 | 用途 |
| --- | --- | --- |
| 样本基础 | 有效 IC 截面少于 20 个 | 标记为样本不足，不评价有效性 |
| 相关强度 | `abs(IC) < 0.02` | 较弱 |
| 相关强度 | `0.02 <= abs(IC) < 0.05` | 中等 |
| 相关强度 | `abs(IC) >= 0.05` | 较强 |
| 稳定性 | `abs(ICIR) < 0.5` | 较弱 |
| 稳定性 | `0.5 <= abs(ICIR) < 1` | 中等 |
| 稳定性 | `abs(ICIR) >= 1` | 较高 |

这些阈值只是课程项目中的描述性分档，不是行业统一标准，也不是显著性检验。负 IC 表示当前因子排序方向与下一期收益负相关，不应被自动解释为“没有价值”；需要反向构造并独立复测。

`1.0.1` 修正样本计数：仅 `ic_series` 中 IC 为有限数值的日期计入“有效截面”和样本不足／稳定性分档；`null`、非有限值和布尔值不计入，并在限制中披露无法计算的日期数。此前版本按序列总长度计数，在缺失 IC 较多时可能高估证据量。该修正不改动已保存的指标或旧 HTML 报告；结论接口会依据当前规则为旧任务动态生成草稿，新任务报告采用新规则。引用报告时应同时核对报告生成时间和 `method.version`。

## 3. 强制风险披露

每份草稿都会说明样本内统计、交易成本、可交易性与数据口径限制。使用 `demo_daily` 时额外强制声明：合成数据只能证明软件流程可运行，不得形成真实市场或投资结论。

生成结果的 `method` 字段会保留规则类型、版本和阈值，便于导师或团队成员复核。研究人员引用草稿前必须检查原始指标，并根据真实数据背景修改措辞。

## 4. 接口与权限

```http
GET /api/v1/research/tasks/{run_id}/conclusion
```

- 仅成功且拥有指标产物的任务可以生成结论；
- 研究员只能查看本人任务；
- 管理员和只读用户可以查看全部任务；
- 接口只读，不修改任务、指标或报告文件。
