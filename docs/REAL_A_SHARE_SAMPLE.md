# 真实 A 股小样本：BaoStock 2024 年上半年

## 当前取得的样本

2026-10-12 已由项目维护者直接连接 BaoStock 服务，固定采集 10 只沪深 A 股从 2024-01-01 至 2024-06-30 的日线（实际有记录日期为 2024-01-02 至 2024-06-28）。本地生成 1,170 行、10 只证券的 UTF-8 标准 CSV，SHA-256 为：

`958e7bdcd5f6269d4e9630f586b91814b40019c043d610b344bd7d5ac381b652`

本地文件为 `data/real/baostock_2024h1_daily.csv`，采集清单为同目录下的 `baostock_2024h1_manifest.json`。这两个文件被 Git 忽略，**不会随公开仓库分发**。若换一台机器，需要重新运行采集脚本；重新获取的内容可能因上游数据修订而与上述哈希不同，应保留各次采集清单并说明差异。

## 数据来源与字段

- 服务：[BaoStock 历史 A 股 K 线 API](https://www.baostock.com/mainContent?file=pythonAPI.md)；Python 包使用 `baostock==0.9.4`，采集方法为 `query_history_k_data_plus`。
- 固定代码：`sh.600000`、`sh.600276`、`sh.600519`、`sh.601318`、`sh.601398`、`sz.000001`、`sz.000333`、`sz.000858`、`sz.002415`、`sz.300750`。这是人工选出的固定股票池，**不是历史指数成分股**。
- 请求参数：`frequency=d`、`adjustflag=1`。根据 [BaoStock 字段文档](https://github.com/zxygithub/baostock/blob/master/docs/pythonAPI.md)，`1` 是后复权；其算法是涨跌幅复权法，可能与其他平台价格不同。
- 映射：`date → trade_date`、`code → 000000.SH/SZ`、`turn → turnover_rate`、`peTTM → pe`；OHLC、成交量、成交额仅换字段名，不猜测单位。`turn` 保留 BaoStock 的百分数单位，不除以 100。`peTTM` 保留原值，但尚未独立核对其财报披露时点。
- 采集脚本拒绝非交易/停牌记录、错误复权标志以及核心价格字段缺失，不前填、插值或生成合成价格。本次 10 只证券各返回 117 行，未触发上述拒绝条件。

## 使用与验证

在项目 Python 环境中安装可选采集依赖；它不属于平台运行时必需依赖：

```bash
python -m pip install baostock==0.9.4
python tools/fetch_real_a_share_sample.py
python tools/verify_real_a_share_sample.py
```

脚本默认拒绝覆盖已有快照。确需重新获取时先备份本地 CSV 与采集清单，再执行 `python tools/fetch_real_a_share_sample.py --refresh`，并核对新的哈希。

然后可用管理员在数据集页面上传本地 CSV，发布新版本，研究员选择该版本进行研究。研究价格口径应选“使用导入的 close”，因为 CSV 的价格已经后复权；不要再选择 `close × adj_factor`。

## 研究与许可边界

2026-10-21 对同一 SHA-256 的本机私有快照新增只读复核：117 个观测日期，每日 10 行、每股 117 行；五因子观测数和验证期交集未变。另用无去极值/标准化的 20 日动量诊断任务，直接从 CSV 价格独立计算全部 96 个逐日 IC，最大绝对差约 `2.22×10⁻¹⁶`。这是额外诊断口径，不等于对默认预处理结果的独立复算；详见 [REAL_A_SHARE_AUDIT_2026-10-21.md](REAL_A_SHARE_AUDIT_2026-10-21.md)。原始 CSV 和清单继续 Git 忽略。

- 固定股票池带有选择偏差/幸存者偏差；短区间、小样本不能推断长期有效性或投资收益。
- 停牌处理规则是本次数据采集门槛，不代表平台已经实现完善的停牌/可交易性模型。
- 财务类 `peTTM` 的实际披露日期和可能的历史修订尚未独立审计；不得把本样本的 PE 检验描述为已消除前视偏差。
- [PyPI 所列 BSD 许可证](https://pypi.org/project/baostock/)针对软件包，不能据此推定行情数据可公开再分发。若课程需要把 CSV 放进公开仓库或提交给外部平台，须先核实数据权利和学校使用方式。仓库目前只保存采集程序、转换规则、摘要哈希和验证结果。
- 项目结果仅用于软件与课程研究验收，不构成投资建议。
