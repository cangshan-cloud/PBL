# 量化投资多因子研发平台阶段进展简报

汇报日期：2026 年 10 月 16 日
项目定位：课程验收；少量研究人员使用；沪深 A 股日频研究；不接实盘交易。
代码基线：`48c751f`（已推送的最近提交）；页面布局优化存在未提交工作，**不计入已完成版本**。

## 一、目前完成到哪里

项目已具备“数据版本 → 因子选择与参数配置 → 异步研究任务 → 统计检验与图表 → HTML 报告 → 复现信息下载”的核心闭环。平台侧采用 Web、API、Celery Worker、PostgreSQL、Redis 五服务结构；产品侧提供数据集、因子库、研究工作台、任务、实验对比、报告及角色权限页面。首期以稳定课程演示为目标，暂不将系统描述为可实盘交易或生产级多人平台。

| 模块 | 当前进展 | 证据与边界 |
| --- | --- | --- |
| 数据与权限 | 已实现 CSV 导入、质量校验、发布版本和管理员／研究员／只读角色 | 内置 `demo_daily` 0.2.0 为 2,400 行、20 只虚拟股票；固定 SHA-256 会前预检。Parquet、通用财务披露时点未实现。 |
| 因子研究 | 六个内置因子、普通单因子、等权多因子、IC／Rank IC／ICIR、分组与成本后多空指标已实现 | 固定黄金样例与后端 191 项测试在 Mac 通过；真实 BaoStock 10 股、1,170 行样本复核了五个有字段支撑的因子。统计结果不是投资收益承诺。 |
| 异步与报告 | 任务状态、日志、取消／重试、HTML 报告和复现 JSON 已实现 | 独立五服务 Compose 项目中完成浏览器提交、Worker 执行、报告预览／下载和摘要核对；最近新增的排队取消／重试为隔离 HTTP 测试，真实 Worker 撤销时效尚未验。 |
| 部署与演示 | Mac OrbStack 隔离部署已验证；十分钟剧本与四责任包材料已建立 | Windows 实机部署暂缓；正式连续口头讲解计时和队长本人产品测试尚未完成。 |

真实 10 股样本及历史沪深 300 数据包为本机私有材料，不随公开仓库分发。历史股票池研究已经有 Mac 私有包验收证据，但成分生效时点、ST 来源状态和数据使用许可仍是限制；正式演示默认使用可离线复现的合成数据。

## 二、当前阶段判断

**核心软件功能已成形，课程最终验收尚未完成。** 目前最需要的是冻结演示范围、完成页面可读性优化和真实浏览器复测，再由队长进行十分钟连续讲解彩排并补入个人产品测试记录。不能用自动测试项数、历史任务截图或代执行材料替代最终验收。

## 三、接下来怎么做

1. 完成当前进行中的页面布局优化，重点检查研究工作台、任务详情、报告预览和实验对比的桌面／窄屏显示；构建与浏览器复测通过后再计入已完成版本。
2. 用固定 `demo_daily` 数据完成一次最终版本的登录、提交任务、查看日志与图表、下载报告、只读权限浏览器回归；保留任务 ID、版本、截图和缺陷记录。
3. 队长完成不超过十分钟的连续口头演示，记录实际分段用时、失败降级和亲测结论；A/B/C/D 责任包按实际执行者更新。
4. 核对最终提交对应的 CI 和报告材料。Windows 部署及 Parquet、中性化、本地模型摘要等扩展项继续作为范围外或后续决策项，不挤占课程验收。

## 四、四人分工口径

沿用已确认的 A 系统架构与集成、B 数据工程与质量、C 因子研究与指标验证、D 产品测试与展示四个责任包，计划责任比例各 25%。B/C/D 姓名、学号和每周投入时间仍待填写。按队长约定，开发与测试证据可由开发者统一代执行和整理，但材料必须写明实际执行者；计划责任比例**不是**个人实际工作量或贡献完成证明。具体任务、交付物和近期动作见配套四人分工 Excel。

## 五、项目结构

平台层负责五服务协作、权限、持久化与异步调度；产品层在其上完成数据版本、因子配置、研究任务、指标检验、实验对比和报告。可直接用于汇报的[项目运行架构图](../outputs/progress-2026-10-16/项目运行架构.png)另提供[可编辑 SVG](../outputs/progress-2026-10-16/项目运行架构.svg)。

| 位置 | 主要职责 |
| --- | --- |
| `frontend/` | React / TypeScript 研究页面 |
| `backend/app/` | FastAPI 接口、权限、数据、因子、任务与报告逻辑 |
| `backend/tests/` | 后端回归测试 |
| `data/sample/`、`data/real/` | 演示及本机真实样本；私有数据不公开分发 |
| `docs/`、`outputs/` | 需求、验收、变更决策与交付材料 |
| `docker-compose.yml` | Web、API、Worker、PostgreSQL、Redis 五服务编排 |
