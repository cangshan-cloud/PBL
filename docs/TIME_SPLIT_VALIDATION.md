# 时间切分 IC 诊断

普通单因子与等权组合任务可以在运行前填写 `validation_start_date`（验证期起始日）；留空则沿用原流程。该参数随实验保存。历史沪深300固定模式暂不支持此可选项。

系统按**信号日期**切分：验证期从指定日期开始；其前最近一个有观测的信号日作为隔离日，不进入研究期或验证期。这样即便该日下一市场日收益落在验证期，也不会进入研究期 IC。因子回看历史仍可使用切分日前的数据，因为这些数据在信号形成时已知。每侧须至少有 3 个切分前信号日、2 个切分后信号日；隔离后研究期至少保留 2 日。样本量不足会使任务失败并给出错误，不伪造空白验证结果。

结构化结果 `time_split` 分别记录研究期和验证期的信号日期范围、观测数、有效 IC 日数、IC 均值、Rank IC 均值、ICIR 与 IC 为正比例，并记录切分日、隔离日。全区间原始指标保持不变。页面、HTML 报告和规则结论会清楚标识该诊断；分段不计算多空净值或可成交收益。IC 缺失时按现有规则排除，指标不填零。

已保存的带切分复现 JSON 可运行 `tools/verify_research_result_consistency.py`，从全区间逐日诊断和 IC 序列复核隔离日、两段计数与摘要指标；核对不需要私有原始 CSV，但也不独立重算因子或 IC。10 股真实样本在临时内存任务上的双因子复核记录见 [2026-10-27 只读验收](REAL_SAMPLE_SPLIT_CONSISTENCY_QA_2026-10-27.md)，决策见 [CHG-20261027-009](changes/2026-10-27-009-time-split-result-audit.md)。

网页每日 IC/Rank IC 图在带切分的 Run 上现明确列出两段实际日期与隔离信号日；按日期查看原值时标注该日属于哪段或范围外。曲线依旧是**全区间原序列**，隔离日若有点仍可见，但不进入任一分段摘要；选中日期属于某段不表示该日 IC 有效。此 UI 分支以浏览器会话内构造响应验收，不能当作旧 Run 的真实分段结果。见 [CHG-20261027-006](changes/2026-10-27-006-ic-split-date-context.md)。

这是对已有历史数据的**回溯时间分段**，不是天然的前瞻样本外证明。只有切分日期、因子与参数在查看验证结果前锁定，且不反复针对验证期调参，验证区间才有相对独立的意义；即便如此，仍需更新的未见数据与独立数据来源复核。课程样例与真实数据结果均不构成投资建议。

规则结论版本 `1.0.3` 对设置切分日的任务采用**验证期 IC**作为标题和分档依据，而非全区间 IC。验证期有效 IC 日少于 20 天时只能给出 `insufficient`；20—59 天即使统计值较好也不升至 `promising`；研究期与验证期 IC 方向相反也不升至 `promising`，且必须显式提示反转。全区间多空、成本和换手仅列为背景证据，不表示验证期交易表现。未设置切分日的任务继续采用原有全区间规则版本 `1.0.2`。

实验对比页及 CSV/HTML 导出分别展示各 Run 已保存的验证期 IC 摘要。混用切分与未切分、切分日不同，或同切分日但有效 IC 日期集合不同都会提示口径风险。原始排名始终是全区间指标排名；**已保存的**验证期摘要未做共同证券样本重算，不含验证期多空收益，也不作为前瞻验证证明。

若对比的所有 Run 使用同一切分日且逐股观测产物可校验，另提供**验证期严格同样本 IC**：取切分日及以后各 Run 共有的“信号日期 × 证券”键，按每个 Run 原预处理参数重算截面 IC，并记录下一日收益标签差异。若缺少产物、日期不一致或没有共同键，则显示不可用原因。这个重算结果与上段“各 Run 已保存验证期摘要”相互独立；仍未统一价格或收益标签、未模拟交易和成本。

对比中的严格同样本 IC 另以所选 Run 的**最少有效 IC 日数**提示证据基础：少于 20 日仅表示可以计算，不评价稳定性；20—59 日样本基础有限；达到 60 日仍仅是历史描述，不能当成显著性或未来表现证明。该提示不替代单任务结论评级。

验证期严格样本同时列出各 Run 的共同观测保留率：验证期共同证券日期观测条数 ÷ 该 Run 已保存的验证期观测条数。它帮助识别“有效日期很多、但交集股票大幅缩小”的情形；比率本身不判定因子优劣，也不改变原验证期摘要。

若已保存的验证期观测数与同一 Run 逐股产物在切分日及以后的条数不一致，对比会提示异常并列出计数；不会用其中一侧悄悄覆盖另一侧。该核对只涉及信号日期分段与条数，不独立验证收益标签或原始行情来源。
